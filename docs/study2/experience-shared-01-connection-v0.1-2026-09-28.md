# EXPERIENCE-SHARED-01：Colab一セル版と使い方

2026-09-28。承認済みの[設計v0.1](../../experiments/ES01/docs/experience-shared-01-plan-v0.1-2026-09-28.md)を実装した。**本人の経験から作った判断を保ちつつ、二人で作った共同方針を別の仕事に使えるか**を測る。今回の準備はオフラインで完了し、実モデルの取得・ロード・生成は0。実GPU上の動作はColabで確認する。

## 使い方

1. [Readable code and current instructions](../../experiments/ES01/generation/README.md)を開き、全文をコピーする。
2. ColabでA100 80GBまたはRTX PRO 6000 Blackwell級のGPUランタイムを選び、一つのセルへ貼って実行する。設定編集・過去ZIPのアップロード・Drive接続は不要。
3. 終了時に自動ダウンロードされる `npp-es01-result-日時-ID.zip` を保管して、このチャットへ返す。自動DLが始まらない場合は、Colab左のファイル欄から同名ZIPをダウンロードする。

追加のAPIや新規有料サービスは使わず、既存Colabの計算資源を使う。初回は公開モデルと依存パッケージの取得がある。原回答・派生物は非公開、削除期限なし。

## 今回の一巡

| 工程 | 回答数 | 渡すもの |
|---|---:|---|
| 本人の判断 SELF | 16 | 本人の二回分の経験 |
| 共同形成 FORM | 32 | 両者の経験・実SELF。応答役には相手の実提案も追加 |
| 後続利用 USE | 96 | 同じ経験と本人の実SELFに、共同記録なし／実共同記録／割付だけ反転したコピー |
| 合計 | **最大144** | 初回16＋実生成物に依存する後続最大128 |

8入力配置×2反復の16分岐経路。同一SELFは同じ反復内の相手条件二枝で共用し、共有前の比較は重複を除いた8対応、共有後は条件ごと16対応とする。

**準備込み60分、1回答最大1024新規トークン、再生成0**。2経路が閉じるごとにColabの一時領域へ途中ZIPを作り、最後に結果ZIPを返す。同じランタイムで再クリックした場合は、追加生成せず照合とZIP返却だけを行う。実行ロックが残っていれば重複開始せず、状態をログへ残す。

誤答、出典違い、共同案の不一致では続行する。JSON構造が受理できなければ依存する後続だけを欠測にし、独立した入力は続ける。OOM・実行例外・時間上限では停止と未取得を記録して閉じる。GPUの空き容量・BF16などの前提を満たさない場合も、モデル設定を勝手に変えず診断ZIPを返す。

## 何を分けて保存・採点するか

- 本人の判断と共同の割付を別フィールドで採点する。共同の合意を保存器が決めたり、本人の回答を正解へ差し戻したりしない。
- 先提案と応答は別記録のまま渡す。不一致なら共同作業の保留を適切な応答として評価し、本人判断は引き続き評価する。
- 割付反転は共同記録内のA/BのPAPER・DIGITALだけを入れ替える。UNDECIDED、本人SELF、経験、出典は変えない。実記録・診断用コピー・変更箇所を併記する。
- 反転後の共同案への忠実性と、経験上の効率を別々に数える。意図した反転による効率低下を「共同記録を使えなかった」と採点しない。
- JSONは厳密解析を先に行い、既知の `json`＋LFの外側フェンスだけを除去できる。内容、ID、欠けたキー、余分な括弧は修復しない。
- 実回答、トークンID、入力全文、親の保存ファイルとhash、正規化前後、採点、欠測理由を予定IDごとに残す。正解表・条件名・プロフィール名はモデル入力へ含めない。

集計は固定規則のコードで行う。主要な記述は本人経験への応答SのSHARED−FACTS差。形成F、共同課題G、忠実性H、利用診断U、出所Z、同じ経路の両立Jを併記する。固定目安のMET／NOT_MET／INCONCLUSIVEは設計を継承し、欠測の上下限と対象外の形成未成立を分ける。p値や母集団への推定は行わない。

## 固定した実行環境

Qwen/Qwen3.5-27B、revision `fc05daec18b0a78c049392ed2e771dde82bdf654`。CU01成功セルの実行部を継承し、transformers 5.17.0／accelerate 1.15.0、BF16、SDPA、non-thinking、batch=1を維持する。temperature=.7、top_p=.8、top_k=20、repetition_penalty=1、入力上限8192。重み・精度・backendの自動フォールバックはしない。

SELFとFORMとUSEは毎回新規コンテキスト。seedは基準2026092801とブロック・反復・役・工程から作り、本人プロフィールとUSE条件を構成要素にしない。二反復は別seedで、GPU実行の完全な決定性を前提としない。
