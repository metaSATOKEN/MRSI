# EU01：Colab一セル版の準備報告

2026-09-28。[承認済み設計](../../experiments/EU01/docs/experience-update-01-plan-v0.1-2026-09-28.md)を、保存物の受渡し・固定採点・結果回収まで実装した。**次は下のPython全文をColabの一セルへ貼れば実行できる。** Drive接続、設定編集、過去ZIPの手動アップロードは不要。

## 使い方

1. [Readable code and current instructions](../../experiments/EU01/generation/README.md)を開き、全文をコピーする。
2. ColabでA100 80GBまたはRTX PRO 6000 Blackwell級のGPUランタイムを選び、一つのセルへ貼って実行する。設定編集・過去ZIPのアップロード・Drive接続は不要。
3. 終了時に自動ダウンロードされる `npp-eu01-result-日時-ID.zip` を保管して、このチャットへ返す。自動DLが始まらない場合は、Colab左のファイル欄から同名ZIPをダウンロードする。

最大128回答、準備込み60分。本人の再提案32→相手の確認32→二役の後続利用64を順に実行する。反転経験と補強経験は同じAC01の全16出発点から比較し、未合意だった一件も引き継ぐ。

誤答・誤参照・未合意は保存して続行する。JSONなどの構造不備は、その回答に依存する後続だけを欠測にする。モデル例外・OOM・時間上限では停止して記録を回収する。自動再生成は行わない。

## 接続した内容

- 元の経験4行、二役の実USE本人判断、実提案・確認記録を埋め込んだ。新しい一経験を加え、二条件ではその成功人数だけを交換する。
- 本人は累積80人、相手は40人の経験なので、成功率を次回各区画40人に換算して共同案を採点する。計算済みの正解・条件名・旧成績はモデルへ渡さない。
- PROPOSEの本人判断と提案、CONFIRMの相手本人判断と返答を、実際に保存された回答から抽出して次へ渡す。誤った内容・出典も修正せず、そのまま追跡する。
- 本人判断L、参照Z、新合意K、最新事実に適合する合意C、後続の忠実性Hを分離。主指標Qは二条件での両立、相手保護I_peerは二条件の相手判断をまとめる。事前の分母・進行目安・欠測上下限を継承する。
- 新しい提案と確認だけをUSEの現行声明として渡す。未合意なら共同のみ保留し、旧合意への自動復帰はしない。

研究モデルはQwen/Qwen3.5-27Bの固定revision、BF16／SDPA／non-thinking、batch1。温度.7／top_p.8／top_k20、入力8192・出力1024tokens、原文16384bytes。既存のtransformers5.17.0／accelerate1.15.0環境設定と生成helperを継承した。モデル・精度・backendの自動切替はない。

Colab以外ではモデル取得前に停止する。ColabでもVRAMとBF16条件を確認してからロードする。Driveをマウントせず、一時領域へ保存する。二条件経路ごとの途中ZIPと終了ZIPを出力し、同じランタイムでセルを再クリックした場合は追加生成せず再集計・ZIP返却だけを行う。既存Colab枠を使用し、新規購入・有料APIは利用しない。原文・生成物は非公開、削除期限なし。
