# FORMATION-GATE-01：実行前計画 v0.1

2026-09-13。**設計・ローカル準備のみ。新規モデル実験はGO待ち。** [設計レビュー](formation-roadmap-review-2026-09-13.md)と[JUDGE-TRANSPORT-FIXの結果](judge-transport-model-results-2026-09-13.md)を受けた、形成だけの小試験。事前カード (see the evidence index)。

## 問いと推奨規模

P/Cの立場や犬猫の好みを割り当てず、同じ事象・指示・役構成から会話を生成すると、**終盤にP優勢が続く群とC優勢が続く群を少なくとも1群ずつ観測できるか**を調べる。長期安定性、集団内の増幅の因果効果、NPP成立は今回の問いに含めない。

推奨は**6群×3役、初期r0＋会話r1/r2の固定3時点**。1群9発言、全54発言。4群案は生成36＋採点8＝44セッション、6群案は54＋12＝66、8群案は72＋16＝88。今回は4群より観測する履歴を2つ増やし、8群への拡大は保留する。6群に検出力保証があるという選定ではない。6群で成立しなければ同じ試験に群を足さない。

| 項目 | 固定する案 |
| --- | --- |
| 群・役 | G01〜G06、各A/B/C。群名は生成入力へ示さない |
| 事象 | R1のt1紙工作会と同一。希望アンケートと入口への距離の手掛かりを保持 |
| 生成 | Luna・medium、全54回で新しいセッション、fork_turns=none |
| 会話 | r0は履歴なし。r1は自群r0全3発言、r2は自群r0/r1全6発言を参照 |
| 採点 | Sol／Luna・medium、各6packet×9説明＝各54評価、計12セッション・108評価 |
| 履歴介入・次事象 | 今回はなし。t2、KEEP／DROP／SWAPは入力にも含めない |
| 上限 | 生成54＋採点12＝66セッション、同時最大2、発行45分＋終了猶予10分 |

「同じ初期条件」は、群間で同じ3役・事象・指示を使う意味。役A/B/Cの名前は異なるが、同じ役のr0入力は6群間でbyte同一にする。役に性格やP/Cの傾向を指定しない。発行順の乱数は計画・匿名化用であり、モデルへ意味を持つseedを与える介入ではない。

## 材料と会話の作り方

材料 (see the evidence index)は、R1のevent1と選択肢をそのまま継承する。生成指示はformed-respond-v0.1 (see the evidence index)を変更せず使う。すでにP寄りだった材料を隠さず、今回は同じ条件で分化の成立可否を測る。新しい均衡材料を同時に混ぜると、形成条件と材料変更の区別がつかなくなるため、材料探索は分化不成立後の別段階にする。

各段階の18発言を全件保存・固定してから次段階を作る。履歴は前ラウンドまでの自群の実出力だけで、r0→r1、各ラウンド内A/B/C順に提示する。同一ラウンドや別群の発言、採点・期待ラベルは渡さない。各役は毎回新セッションで、過去の役の継続は明示された役名と会話記録で表す。常駐した個体内部の状態を保持したとは呼ばない。

生成出力はexplanationとpreferenceのJSON。説明は非空〜400文字（100〜220文字は目安）、preferenceはDOG/CAT/BOTH/UNDECIDED。重複JSONキーなど値が曖昧になる構造は拒否する。犬猫選択は各ラウンドの別集計とし、P/C票に変換しない。生の出力を逐語のまま履歴に使い、要約・訂正・選別しない。

人数や会話回数の別条件は今回は比較しない。分かるのは**3役×2会話ラウンドで、この判定条件を満たしたか**まで。十分な人数・最適なラウンド数を示す試験ではない。

## 採点の提示と意味上の注意

新形式プロンプト (see the evidence index)と凍結済み受理器 (see the evidence index)を変更せず使う。各採点者は現在事象・匿名説明・分類指示のみを読み、群名・役名・ラウンド・犬猫選択・他の判定・研究仮説を見ない。全54説明を採点する。

同じ群の9発言をひとかたまりで渡さず、**6群と3時点を混ぜた9件packetを6つ**作る。各packetは各時点3件で、全6群から1〜2件ずつ含む。割当は結果を見る前に固定し、説明内容で並べ替えない。Sol／Lunaには同じpacket構成・項目順を、別の新規セッションで提示する。

ラベル・引用・理由の全ID完全一致と各1回、引用の連続部分文字列一致、非空理由を機械検査する。packetが不正なら、そのpacketの9評価を欠損として予定分母に残す。ラベル票だけの部分救済・再採点はしない。UNSCORABLEは意味測定ができない状態として扱い、MIXED／OTHERへ変換しない。

前試験の「主因として留保」という曖昧な理由と、「どちらも」という文脈依存の引用は注意例として分析者の記録に残す。判定者へこれらの例や新しい意味指示を追加しない。全108評価の非盲検の補助点検では、本文・引用・理由の整合と文脈依存を記録するが、ゲートのラベルを裁量で書き換えない。機械的な形成判定と、意味測定上の懸念は別に報告し、懸念があれば次段階の設計で取り扱う。

## 群の状態を決める規則

各採点者について、各群・各ラウンドの3票をP/C/MIXED/OTHER/UNSCORABLE/欠損に分けて保存する。3票がすべてP/C/MIXED/OTHERの有効票であるとき、PまたはCが2票以上ならそのラウンドの優勢とする。そうでなければNO_DOMINANT。UNSCORABLEまたは欠損が1つでもあればUNKNOWNとする。

群の履歴9発言すべてに有効票があり、**r1とr2で同じPまたはCがそれぞれ2／3以上**ならSTABLE_P／STABLE_Cとする。それ以外の完全観測群はNO_STABLE_DIRECTION。9発言の合計多数決はしない。1発言でも測定不能ならUNKNOWNとする。この「安定」は2つの会話ラウンドの間で優勢方向が続いたという限定的な名称。

| r0 → r1 → r2の優勢 | 群状態 | 解釈 |
| --- | --- | --- |
| P → P → P | STABLE_P | 初期の優勢が維持された |
| NO_DOMINANT → C → C | STABLE_C | 初期にない優勢が会話後に現れた |
| P → C → C | STABLE_C | 初期の優勢から反転した |
| P → P → C | NO_STABLE_DIRECTION | 最終Cでも終盤2回の方向が揃わない |
| NO_DOMINANT → NO_DOMINANT → NO_DOMINANT | NO_STABLE_DIRECTION | 混在や判断保留が続いた |
| UNKNOWNを含む | UNKNOWN | 完全な軌跡を評価できない |

r0の状態との関係も記録し、最初から異なっていた群の維持を、会話による新たな分岐と混同しない。同じ役の3回の発言を独立票・独立集団Nとは扱わない。

## 全体のPASS／NO_DIFFERENTIATION／INCONCLUSIVE

まず54生成の入力経路・保存が成立し、108採点が全て有効フレーム（P/C/MIXED/OTHER）であることを要求する。1つでも欠損・UNSCORABLEがあれば、観測できた群の状態も残した上で、全体はINCONCLUSIVE。初回は欠損からの推定・穴埋めを行わない保守的なゲートとする。

完全観測の場合、SolとLunaそれぞれについてP安定群とC安定群が共存したかを計算する。次に、両者が同じ群をSTABLE_Pとした集合P*、両者が同じ群をSTABLE_Cとした集合C*を作る。

| 全体判定 | 条件 |
| --- | --- |
| PASS_DIFFERENTIATION | P*とC*がともに1群以上。両採点者が認める反対方向の履歴が揃う |
| NO_DIFFERENTIATION | 完全観測だが、Sol単独でもLuna単独でもP安定群とC安定群の共存が成立しない |
| INCONCLUSIVE | 観測欠損、または上記以外の採点者不一致。片方だけ共存を認める場合や、両者は共存を認めても共通の反対群がない場合 |

Solを主要な記述集計、Lunaを別判定として併記するが、次の履歴交換へ進める候補群は両者一致のP*／C*に限る。別群について不一致があっても、完全観測でP*とC*が存在すれば最小の存在条件は満たす。不一致群も分母から消さない。

全6群の状態表、各ラウンドの分布、r0からの変化、採点一致・不一致、欠損、犬猫選択を報告する。P*・C*を各群IDの昇順で組み合わせた候補ペアを記録し、数はmin(|P*|, |C*|)。余った群も全体表に残す。これは次の試験を実行する指示ではない。形成成功の全群分母と、将来の適格群だけの条件付き効果を区別する。

P/C各1群は「履歴を交換する比較を組める」最小条件であり、再現性や検出力の確認ではない。p値、NPP値、有意になるまでの追加は行わない。

## 上限・失敗・保存

最大66作成セッション、同時最大2。最初の成功起動から45分で新規発行終了、10分の終了猶予を加えて最大55分。セッション未作成を確認した起動前失敗のみ全体最大3回まで同じ予定枠の起動をやり直せる。作成の有無が不明なら再発行せず停止する。返却済み応答の修復再発行・意味の再採点・モデル代替0。Codex利用枠を使い、追加支払い・直接課金API・SNS取得0。

生成段階で不正や欠損があれば、当該段階の予定発行を閉じて全試験を停止し、依存する次段階は作らない。入力未到達・別入力参照・通信・保存障害・固定hashの不一致は検出時に新規発行停止。採点の形式不正だけなら残りの予定採点は続け、全体INCONCLUSIVEに欠損を残す。途中のP/C分布を理由に延長・打切り・群追加・材料変更はしない。

原出力・逐語履歴・ID対応・可視操作は新runのrestricted（dir0700／file0600）に保存し、既存の期限2026-10-12 17:41:23 JSTを継承。入力の完全提示と操作を確認する。rootログの保存表現のhashを平文wrapperのhashと直接比較しない。保存表現の指紋と、可視spawn引数の平文照合を分けて残す。

事前に材料・指示・全54生成割当・全12採点割当・順序・判定器・テストを固定する。r1/r2と採点本文は未来の実出力に依存するため、先行段階の全出力を閉鎖した後にのみ作成する。旧R1・JUDGE-TRANSPORTの原票や結果、凍結元は変更しない。

## 終了後の分岐

- PASS：反対履歴の交換を行うFORMED-HISTORY-02の設計へ。今回得た履歴の存在確認と、交換による未来解釈への影響を分ける。
- NO_DIFFERENTIATION：この材料・指示・モデル・会話条件で成立しなかったと記録。材料だけが原因とは断定せず、履歴なし材料のP/Cバランス点検を別の固定小試験として設計する。
- INCONCLUSIVE：輸送・欠損・測定不一致のどれで判定不能かを先に分ける。群追加やP/C指定を使って穴埋めしない。

材料探索でも自然分岐しなければ、人格や結論を直接指定しない小さなランダムseedの設計へ進む。その段階で無交流対照を置き、seedの持越しと会話による増幅を分ける。今回の無対照会話だけで増幅を認定しない。各分岐の実行範囲は別途具体化する。
