# INDIVIDUAL-SHARED-01 — 固有情報と共有経験を両方使えるか

2026-09-16 / 草案 v0.1 / **DESIGN_OFFLINE_CHECKED_NOT_DISPATCH_READY**。

ユーザーが、大きな安定性再現試験をいったん保留し、研究全体のテーゼに沿った小規模実験を先に設計する方針へ同意した。本書はその最初の案。**材料・比較・予定64回答・解析方針までの設計で、実測は未承認・未実施。** 本文と割付をローカルで点検し、新しいモデル呼出しは0。

## 1. 最初の一問

> 本人だけが持つ受付記録と、チームが共有した実施記録を一緒に渡したとき、本人の担当に合う判断と、共有経験を使う判断を両立できるか。

まず「個体固有の情報が後の判断に効く」という、個体性の最小の観測対象に絞る。本人固有の情報と共有記録の有無をそれぞれ変え、両方を使った回答が得られるかを見る。

**今回の記録は研究者が用意する。会話から自発的に個体性や共有状態が形成される実験ではない。** 犬派／猫派の人格やP/Cの説明立場を指定するのではなく、役ごとに受け取った予約情報を違える。測るのは、外から与えた固有情報と共有経験の利用であり、主体の内的な好み、自然に形成された個体性、長期共存の成立ではない。

この試験がうまくいっても、得られるのは最小課題での両立の観測。会話から作った記録や、自由な判断への一般化は次の別試験で確かめる。

## 2. 具体例：犬の希望と、みんなの経験を同時に使う

同じチームの担当者AとBに、それぞれの予約者への工作キットの袋と、全員への案内方法を選ばせる。

| 記録 | 内容の例 |
| --- | --- |
| Aだけが受け取った個別記録 | Aの予約者は犬の絵柄を希望している。 |
| Bだけが受け取った個別記録 | Bの予約者は猫の絵柄を希望している。 |
| チームの共通記録 | 前回の来場者全体では犬の希望が多かった。紙の案内は全員に届き、デジタル案内は一部に届かなかった。 |
| 今回の依頼 | 担当予約者の希望に合う絵柄と、全員に届けられる案内方法を選ぶ。予約希望・会場・端末や通信条件は前回から変わっていない。 |

両方の記録があるとき、この設定では **Aは犬＋紙、Bは猫＋紙** が記録に合う。共通の経験は使うが、Bの担当予約者の希望を全体の多数派へ置き換えない。

ここでの多数派は来場者全体の記録であり、人工主体A/Bの合意ではない。Bが犬を選んだとしても、それだけで心理的同調や人格の同一化と断定せず、「本人固有の情報に合わない選択」と記録する。

もう一つの材料は作品展示会の入場名札。両材料に、犬／猫と紙／デジタルの対応を反転した別設定を用意する。いつも犬・いつも紙を選ぶ方略と、入力に応じた判断を分ける。材料はモデルへ試して選別しない。

## 3. 比較は4条件

| 条件 | 個別記録 | 共通記録 | 記録から選べること |
| --- | --- | --- | --- |
| NONE | なし | なし | どちらも不明。推測せずUNKNOWNにできるかも観測する。 |
| PRIVATE | あり | なし | 本人の予約者に合う絵柄。共通案内方法は不明。 |
| SHARED | なし | あり | 共通案内方法。全体の多数派だけでは本人の予約希望は分からない。 |
| BOTH | あり | あり | 本人の予約希望と共有経験に合う二つの判断。 |

全条件で現在の依頼と一般的な判断規則は同じ。除去した記録は「利用可能な記録はありません」とする。個別／共通の見出し自体は維持する。

PRIVATE→BOTHで、共有を加えたときに個別判断が変わるかを見る。SHARED→BOTHで個別情報の追加、PRIVATE→BOTHで共通情報の追加が、それぞれ対応する判断に効くかを見る。NONEは情報がないときの回答傾向を示す。

記録の有無によって情報量・長さも変わるため、これは記録を渡す総効果の比較。記録の分離表示そのものが優れているという因果結論にはしない。混在表示と分離表示の比較は今回追加しない。

## 4. 規模と割付

| 項目 | 提案する固定範囲 |
| --- | --- |
| 材料 | 工作会・展示会の2題材 |
| 設定 | 各題材に反転前／反転後の2設定、計4設定 |
| 担当者 | 各設定A/Bの2役、計8役別入力単位 |
| 比較 | 上記4条件 |
| 反復 | 同じ入力を2回ずつ。各回は新しい文脈で、前の回答を渡さない |
| 生成 | **2題材×2設定×2役×4条件×2反復＝64回答**、各条件16回答 |
| 生成モデル案 | 既存経路のLuna・medium。追加の採点LLMは使わない |

Aが常に犬、紙が常に正解という材料にはしない。BOTHの16回答では、犬／猫×紙／デジタルの4組合せが各4回答。多数派と本人希望が一致／不一致のケースも各8回答。個別→共通、共通→個別の表示順を役・材料で釣り合わせ、反転設定と2反復の間ではその順序を保つ。

第1波は全32入力を事前seedで並べ、第2波は逆順で同じ入力を送る。群内会話や回答同士の参照はない。seedは発行順用で、モデル生成の乱数を固定するものではない。

4設定は研究者が作った反転条件であり、4つの自然形成群や独立した4集団とは呼ばない。独立の材料は固定2題材、役・条件・2反復には依存がある。64回答を独立集団Nへ読み替えず、統計的有意差や一般化を目的にした規模ではない。

## 5. 採点は、曖昧な説明分類から切り離す

回答は次の4欄だけにする。

```json
{"mascot":"DOG","mascot_sources":["R17"],"channel":"PAPER","channel_sources":["R42"]}
```

mascotはDOG/CAT/UNKNOWN、channelはPAPER/DIGITAL/UNKNOWN。sourcesは使った記録IDの配列で、UNKNOWNなら空配列を求める。本人の個別記録はR17、共通記録はR42。IDに犬猫・紙デジタルの正答を埋め込まない。自由な理由文は要求しない。

この例は操作者用で、モデルに正答例として渡さない。モデル入力には設定名・条件名・反復番号・gold・仮説を含めない。渡す本文は全32入力案 (see the evidence index)に保存した。

選択の採点は、材料原本の申込情報と到達結果を照合する決定論的処理。自由記述の意味や人格の良し悪しを自動判定したことにはしない。LLM採点者の多数決も不要。記録IDの申告は真の内部参照過程の証明ではなく、出所回答の正誤として副次的に扱う。

### 主に並べる値

各条件の予定16回答を分母にする。Iは世界設定上の本人希望と絵柄が一致した割合、Gは世界設定上の全員に届く方法と案内方法が一致した割合。UNKNOWNは有効な回答だが、I/Gの対象選択一致では0とする。

| 指標 | 意味 |
| --- | --- |
| **J_BOTH** | BOTHで絵柄と案内方法が同時に記録と一致した割合。両立の主な記述値。 |
| ΔI＝I_BOTH−I_SHARED | 共通記録だけのときに比べ、個別記録を加えると本人に合う判断が増えるか。 |
| ΔG＝G_BOTH−G_PRIVATE | 個別記録だけのときに比べ、共通記録を加えると共有経験に合う判断が増えるか。 |
| L＝I_BOTH−I_PRIVATE | 共有を加えた後の個別判断の変化。負なら、この標本では本人情報に合う選択が減った。 |

記録がない条件でたまたま世界設定と一致しても、記憶利用の成功とは呼ばない。I/Gは比較用の選択一致として計算し、情報がない項目でのUNKNOWN率と、根拠なしに特定選択をした率を必ず別に示す。

さらに、全4条件のI/G、材料・役・設定・反復別の選択、本人希望と多数派が食い違う8件のBOTH回答、出所IDの一致・利用不能なID・UNKNOWNなのに根拠を付けた回答、2反復の不一致を記載する。出所IDだけの誤りで選択値を研究者が修正しない。

Jが高いだけで個体情報の利用を認定せず、ΔI/ΔGと対照を一緒に読む。L=0でも、広い条件で悪影響がないという同等性・非劣性の証明にはしない。

### 設計時の予想と反対の観測

予想はΔI>0かつΔG>0で、共有後にも本人情報の利用が残ること。BOTHで両方を使えず、どちらかの差が0以下なら、その方向の利用をこの試験では支持しない。ΔG>0とL<0が同時に出る場合は、共有経験の利用と個別判断の低下が併存したと報告する。

符号は固定標本内の記述であり、有意性ではない。小差、反復の揺れ、材料差を残す。陽性にするための成功率閾値、p値、追加Nは置かない。

## 6. 欠測、構造不備、取得の終了

JSONが解析でき、4キー・型・選択肢が契約に合えば、選択と出所をそのまま保存する。原文にないID、根拠の取り違え、UNKNOWNと根拠の不整合は出所回答の誤りとして残し、望む答えになるまで再生成しない。

JSONが壊れている、必要欄がない、余分な本文がある等はその回答の構造欠測として保存する。局所的な出力不備だけなら、そのセルを再発行せず予定の残りを進める。これは新試験の提案であり、旧試験の停止規則を遡って変更しない。

欠測は不正解0ともUNKNOWNとも同一視しない。予定64回答・各条件16の分母を維持し、未知の選択を許容した結果の上下限を出す。同じ回答がJ/I/G/差に現れる場合は同じ仮の選択を共有し、指標間で都合よく別の正解を補わない。これは欠測感度で、信頼区間ではない。

- 全64回答が構造上有効：取得・記述集計完了として閉じる。
- 予定要求を終え、構造欠測が残る：欠測付きで閉じ、感度範囲と記録を残す。
- 輸送故障・入力混入・時限・上限で取得途中停止：取得不成立として既取得と未発行を分けて閉じる。

いずれも自動の追加試験・差し戻し・採点LLMへの切替をしない。新しい正答形式なので、旧P/C採点基準v0.4や旧理由欄の再提出を流用しない。

## 7. トークンと時間をどう抑えるか

通常64生成要求、採点LLM0。空の明示的混雑への再送は同一入力を初回含め最大3試行、30/90秒待機、**試験全体で追加4要求まで、物理要求最大68**という案。既存の有限再送条件を使い、部分出力・timeout・未知の故障は再生成しない。

取得稼働の上限案は45分、同時1。二つの波で同じ予算を共有し、後半で時計をリセットしない。残り200秒以下で新しい要求を出さない。追加支払い0、既存経路、架空材料のみ。保存期限は現行の2026-10-12 17:41:23 JSTを継承する。

全予定入力の合計は**39,184文字**、各入力559〜667文字（生成指示を含む、通信包絡は除く）。自由理由文と長い会話履歴を省いた。通常要求数はHS02の960に対して約6.7%だが、**要求数比や文字数はトークン消費比ではない**。推論・通信包絡・運転側の処理もあるため、トークンの正確な上限を今回の設計検査で保証しない。準備で計測できる入力・出力usageを確認し、推定と実測、取得できない内訳を分けて報告する。

この設計での節約は、採点用の240要求を置かないこと、短い入力と出力、固定64回答で閉じることによる。送信器全体の再実装はせず、新しい入力・JSON契約・決定論的集計を接続する部分だけ点検する。

| 1本目の結果 | 次の候補 |
| --- | --- |
| 参照記録を使う最小課題が成立し、両方の利用が観測される | 固定された短い相互作用から記録を形成する小試験へ。自発的形成・個体の過去判断への持ち越しを追加の対象にする。 |
| 共有後に本人情報が使われにくい、または一方だけに従う | 内容を変えず、個別記録と共有記録の提示方法を比較する一つの小試験へ。どのケースで起きたかを先に固定する。 |
| 課題の規則・入力・出力形式が成立しない | 失敗箇所を具体化して必要な修正だけ行う。課題の不成立を個体性の喪失や共有の無効と解釈しない。修正版を実走するなら2本目に数える。 |

境界が曖昧でも、望む結果になるまで小試験を連ねない。測定と比較対象が固まったところで、未使用材料・新しい応答による確認試験を別途設計する。既存HS02を再開するか、新しい問いの確認へ予算を回すかも、このチェックポイントかユーザーの再指定で決める。

全員が正答しても、個体性の成立や記憶設計の優劣は確定しない。この易しい課題を同じまま大規模化する理由にはせず、形成過程を加える等、次に分ける問いを選ぶ。
