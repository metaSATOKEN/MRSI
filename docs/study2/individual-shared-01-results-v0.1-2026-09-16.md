# INDIVIDUAL-SHARED-01 — 固有情報と共有経験の利用：実測結果 v0.1

2026-09-16 / **COMPLETE_DESCRIPTIVE** / 予定64回答を取得・集計・別照合して閉鎖。

**この最小課題では、本人固有の情報に合う判断と、共有経験に合う判断を両立できた。** 両方の記録を渡した16回答すべてで二つの選択が記録に一致した。予約者の希望と来場者全体の多数派が食い違う8回答でも、本人の担当予約者の希望を保ち、案内方法にはチーム共通の成功経験を使った。

これは、研究者が用意した短い記録と明示的な判断規則を使えることの観測。会話から個体性が生まれたこと、主体自身の好み、内的な記憶、長期共存の成立までは測っていない。

## 何が起きたか

| 渡した記録 | 本人の担当に合う絵柄 | 共通の経験に合う案内方法 |
| --- | --- | --- |
| なし（16回答） | 全16回答がUNKNOWN | 全16回答がUNKNOWN |
| 個別だけ（16回答） | 全16回答が予約希望に一致 | 全16回答がUNKNOWN |
| 共通だけ（16回答） | 全16回答がUNKNOWN | 全16回答が成功方法に一致 |
| 両方（16回答） | 全16回答が予約希望に一致 | 全16回答が成功方法に一致 |

情報がない項目で、犬・猫や紙・デジタルを根拠なく選んだ例は0。UNKNOWNは有効な回答で、必要な記録がない条件では設計上期待した選択だった。

例えば、工作会の担当者Bは「予約者が猫の袋を希望した」という個別記録を持つ。一方、共通記録には「来場者全体は犬希望が多数」「紙の案内が全員に届いた」と書かれている。この場合の実回答は以下だった。

```json
{"mascot":"CAT","mascot_sources":["R17"],"channel":"PAPER","channel_sources":["R42"]}
```

猫という個別の選択と、紙という共通の選択が一つの回答で成立した。保存原文 (see the evidence index)。これは予約者の希望への対応であり、担当者自身が猫派という意味ではない。

## 事前に決めた指標

各条件の固定分母は16。Iは絵柄と世界設定上の本人希望の一致、Gは案内方法と世界設定上の成功方法の一致。

| 指標 | 実測値 | 読み方 |
| --- | --- | --- |
| J_BOTH | 16/16＝1 | 両記録があると二つの判断を同時に満たした |
| ΔI＝I_BOTH−I_SHARED | 1−0＝+1 | 個別記録を追加すると、不明回答から本人希望に合う選択へ変わった |
| ΔG＝G_BOTH−G_PRIVATE | 1−0＝+1 | 共通記録を追加すると、不明回答から成功方法に合う選択へ変わった |
| L＝I_BOTH−I_PRIVATE | 1−1＝0 | この標本では、共有を加えたことによる個別判断の低下を観測しなかった |

ΔI/ΔGの対照側が0なのは、全件UNKNOWNだったため。情報のない条件で誤った特定選択をしたという意味ではない。大きな差は、明示された情報の有無に応じて選択できる課題で得た値であり、一般的な人格保存効果の大きさには読み替えない。

欠測0のため、事前指定した欠測感度の上下限は各実測値に一致した。p値・信頼区間は算出していない。2題材・反転2設定・2役・4条件・2反復の固定標本で、64の独立集団ではない。L=0は同等性・非劣性の証明ではない。

## 補助的な確認

- 本人希望と多数派が食い違うBOTHの8回答でも、I/Gとも8/8一致した。
- 同じ入力を2回送った32組は、選択・申告した記録IDとも不一致0。これは各入力2回での一致であり、広い再現性の保証ではない。

## この結果で次をどうするか

設計時の「ΔI>0かつΔG>0」という予想に、この固定標本は一致した。参照記録を使う最小課題は成立したと扱える。一方、明示的な規則に従って二つの短い事実を参照するだけでも説明できるため、共有記憶の設計優位や自発的な個体性の保存は未確立。

**次の推奨は、短い固定の相互作用から生じた個別判断・共有記録でも、同じ使い分けが残るかを測る小試験の設計。** 今回の容易な課題で全件一致したことを理由に、同じ課題のNを増やすことは勧めない。形成過程を一段加え、何を本人固有の情報として維持したいかを先に定義する。本人だけの情報を答えに反映できることと、自分の過去の判断や立場を維持・更新することを分けて設計する。

次試験の実行は未承認。今回を含め最大2本の小試験で一度グランドデザインへ戻る方針を維持し、HISTORY-STABILITY-02は実測前保留のまま。今回の結果を同一化・硬直化・誤帰属がない長期社会の証明へ昇格させない。
