# INDIVIDUAL-SHARED-02 — 経験の交換で作った記録を、本人ごとの判断へ持ち越せるか

2026-09-16 / 草案 v0.1 / **DESIGN_OFFLINE_CHECKED_NOT_DISPATCH_READY**。

ユーザーの「よしゃ！いいね！次行こう！」を、直前に提案した第2小試験の設計への了承として具体化した。本書はローカル設計。実行器への接続・実測は未実施で、新規モデル要求0。

## 1. 前の実験から一段だけ加えるもの

IS01では、外から用意した個別記録と共通記録を両方渡すと、16/16回答で二つの判断を両立した。次は**最初から完成した共通記録を渡さず、各担当者が持つ部分的な経験を交換して、共通の案内方法を決める過程**を加える。

問いは「この短い交換を経て保存した記録を、新しい文脈へ渡しても、本人の担当に合う選択と、全員に届く共通案内を両立できるか」。会話記録の追加で本人情報に沿う選択が崩れるかも測る。

今回も犬猫は**予約者の希望**であり、主体自身の好き嫌いや人格を指定しない。初期の違いは異なる受付情報から作る。完全自発的な選好の分化、内的な永続記憶、長期共存は未検証のまま。自由な雑談ではなく、4欄のJSONを発言カードとして交換する限定課題である。

## 2. 二人に別々の経験を渡す

材料は工作会の袋と展示会の名札。各題材に反転2設定、計4組。各組はA/Bの二役で、役ごとの予約希望は犬／猫で異なる。紙／デジタルのどちらが全員に届くかと、どちらの役が失敗を観測したかも反転・釣合いを取る。4組は研究者が作った設定であり、自然発生した4集団ではない。

例えば工作会では、Aの予約者は犬、Bの予約者は猫を希望している。

| 最初に知っている範囲 | 紙の案内 | デジタル案内 |
| --- | --- | --- |
| Aが担当した来場者 | 全員に届いた | 全員に届いた |
| Bが担当した来場者 | 全員に届いた | 一部に届かなかった |

AはAの観測票だけ、BはBの観測票だけを最初に受け取る。対象者はA/Bの担当分で尽くされ、重なりはない。**両方の担当範囲で全員に届いたことを確認した方法だけを、全体向けの方法として選ぶ**。他方の範囲が分からなければUNKNOWNとする。

個別情報から絵柄は決められるが、初期には全体向けの案内を確定できない。観測票を持ち寄った後に初めて全体の条件がそろう。成功した方法を直接「群の結論」として渡さず、二人の発言として同じ方法に到達するかを観測する。

**観測事実は研究者が固定したもの**。それを相手へ渡す共有台帳は機械的に組み立て、モデルに観測の原文を書き直させない。一方、そこから選んだ絵柄・案内方法はモデルが出力した原文を保存する。「共有された観測」と「誰が何を選んだか」を分けて持つ。架空の成功経験そのものが会話から自発生成されたとは呼ばない。

## 3. 形成は初期回答＋2ラウンドで固定

全回答は既存経路のLuna・medium、操作ツールなし、新しい文脈で生成する。

| 時点 | 各役が見るもの | 要求数 |
| --- | --- | ---: |
| r0：交換前 | 自分の予約票と自分の担当範囲の観測票。相手の情報なし | 4組×2役＝8 |
| r1：第1交換 | 自分の予約票、両者の観測票、両者のr0原文 | 8 |
| r2：第2交換 | r1と同じ原票、両者のr0/r1原文 | 8 |

同じラウンドの発言を相互に見せない。全組の当該ラウンドを閉じてから次の入力を作る。自分のr0と相手のr0は原文・話者・時点を別欄で保持する。r1/r2で同調や同じ絵柄を要求しない。

初期・途中・最終を全て残す。最終回答が揃ったからといって、それだけを抜き出して形成済みとしない。初期の本人情報利用、r1での変化、r2での最終状態を組ごとに併記する。会話の延長、望む回答への修正、組の追加・差替えはしない。

### 形成の判定F（記述の前提ゲート）

組gについて、次をすべて満たしたときF_g=1とする。

1. r0の両役の絵柄が、それぞれの予約希望と一致する。予約希望は反対なので、初期選択も異なる。
2. r2の両役が、それぞれの予約希望に合う異なる絵柄を選ぶ。
3. r2の両役が、両担当範囲で全員に届いた同じ案内方法を選ぶ。

有効回答で条件を満たさなければF_g=0。UNKNOWNは有効で、必要な特定選択をしていなければ0。構造欠測は未知として扱い、既知の不成立条件があればF=0、そうでなければF∈{0,1}を残す。

全4組が観測可能でF=0なら**NO_JOINT_FORMATION**。Fが少なくとも1組で1なら**OBSERVED_JOINT_FORMATION**と件数を報告する。未知のため少なくとも1組の成立の有無が定まらなければ**INCONCLUSIVE_FORMATION**。これは一般的な集団形成の可否や統計的な成功判定ではない。

**このゲートでプローブ対象の組を選ばない。** F=0でも、入力が構造上組める全組で次の予定比較を行い、分母は全4組のままにする。どの組もF=0なら、プローブで正答が出ても「形成された状態の持越し」という解釈は成立しない。初期からr2までに情報は増えるため、r2の一致だけで社会的相互作用の因果効果は認定しない。

## 4. 形成後の比較は3条件

形成した同じ原本から、次の3種類の入力を作る。いずれも新しい文脈・同じ役で、他のプローブの回答は渡さない。今回も予約希望・担当範囲・端末条件が変わらない「次回の受付」を課題にする。反証情報への更新は別の問いとして保留する。

| 条件 | 渡す記録 | 分けたいもの |
| --- | --- | --- |
| SELF | 自分の予約票・自分の観測票・自分のr0原文 | 本人の情報は使えるが、相手範囲を知らない基準 |
| FACTS | SELF＋相手範囲の原観測票 | 全体の観測事実がそろえば判断できるか |
| DIALOGUE | FACTS＋相手のr0・両者のr1/r2原文 | 観測事実が同じでも、交換で生じた判断の記録を加えて本人ごとの選択が保たれるか |

DIALOGUEの自分のr0はSELFブロックに一度だけ載せる。会話原文は合計6発言分が参照可能だが、重複して再掲しない。FACTS/DIALOGUEには同じ観測原票がある。相手の**予約票そのもの**はどのプローブにも渡さない。DIALOGUE内の相手の絵柄選択は、相手が述べた内容として残る。

SELF→DIALOGUEの案内選択の差は、追加事実と判断履歴を含む総効果。**DIALOGUE−FACTS**では観測事実の不足を揃えられるが、長さ、他者への接触、選択の反復、帰属表示等は分離されない。また、相互作用なしで形成させた別群との比較はないため、会話が形成を引き起こしたという純効果は推定しない。

FACTSもDIALOGUEも全件正答なら、「会話記録を加えたこの最小条件では使い分けを損なわなかった」と記述する。会話の有益性や表示方式の優位を認定しない。DIALOGUEが低ければ、観測事実が同じでも判断履歴の追加と低下が併存した標本として残す。

## 6. 出力・入力と採点

### 出力はIS01と同じ4欄

`mascot`はDOG/CAT/UNKNOWN、`channel`はPAPER/DIGITAL/UNKNOWN、各`*_sources`は記録IDの文字列配列。JSON以外の文章や自由理由は要求しない。UNKNOWNの出所は空配列を指示する。

重複キー・余分キー・型不正・列挙外選択・JSON外の文は構造欠測。新試験の保存・再投入上限として、1回答はUTF-8で4096bytesまで。出所の誤りは選択を書き換えずに保持する。未知IDや重複IDを望む値へ修正する再生成は行わない。

出所は、**利用可能ID／利用不能ID、自分／他者の判断／直接の観測票という種類**を記録する。正しい選択に対してどの出所集合が十分な証明か、という意味採点は今回追加しない。source IDだけで「内部で実際に参照した」「帰属誤りが全てない」と判定しない。私的な予約票のIDが相手発言のsourcesに書かれていても、その票の本文を受け取った扱いにはしない。

1入力（生成指示＋場面・記録の本文）はUTF-8で32768bytesまでとし、超過は入力構築不成立として閉じる。未来・別組・別条件のプローブ・同ラウンド発言を入れない。生成原文は資料として表示し、命令として実行しない。意味の良否による文の削除・要約・言い換えをしない。

### 指標を分ける

I/GはIS01と同じ世界設定上の選択一致。SELFの案内UNKNOWNは妥当な回答だが、Gでは0として記録する。予約希望に反する初期回答を維持したことは「個体性保存の成功」としない。

組g・プローブ反復r・条件cで、A/Bがともに絵柄と案内方法を正しく選んだときJ_grc=1、それ以外は0。

| 指標 | 定義・用途 |
| --- | --- |
| 形成F | F_gの成立件数／予定4組。形成と持越しを分ける |
| **E_DIALOGUE** | (1/8)Σ_gΣ_r F_g×J_gr,DIALOGUE。初期差→終盤の両立→次回の両立まで通った割合。主な一連の記述値 |
| J_c | (1/8)Σ_gΣ_r J_grc。形成の良否にかかわらず全4組を含めた条件別の両立 |
| D＝J_DIALOGUE−J_FACTS | 完全な観測事実に、判断履歴を足した後の差 |
| L＝I_DIALOGUE−I_SELF | 本人情報に合う選択が記録交換後に減るか。I_cは各条件16回答の平均 |
| A＝G_DIALOGUE−G_SELF | 他者の観測を含む記録で全体向け選択が増えるか。G_cも固定16回答の平均 |

予想はF=4/4、E_DIALOGUE=1、J_FACTS=J_DIALOGUE=1、L=0、A>0。D=0でも今回の目的は満たし得る。予想と違う値・未成立・負の差もそのまま記録する。小標本の点一致や0差を同等性・非劣性の証明にしない。p値、事後の成功率閾値、正の差になるまでの追加Nは置かない。

全時点・全条件の選択、I/G、r0とr2の変更方向、r1→r2の揺れ、自己r0との一致、出所種別、2反復の不一致を併記する。初期と最終が一致するだけで正しいと数えず、世界設定との一致も必ず示す。

### 欠測と依存

生成の構造欠測はそのセルを再発行しない。形成段階では当該ラウンドの予定セルを閉じ、必要な原本が揃わない組の後続ラウンドと**3条件すべてのプローブ**を依存未成立として未発行にする。他の組は予定どおり進める。これは結果の良い組の選別ではなく入力構築可能性の制約で、欠けた組も4組の分母から除かない。F=0という意味上の未成立は停止・除外の理由にしない。

プローブの構造欠測は当該回答だけを未知とし、他の予定セルを続ける。輸送故障、部分出力、未知の失敗、保存／封印／入力混入異常、時限・上限は全体停止。取得・集計状態と形成ゲートは別に報告する。

欠測・依存未発行・輸送失敗をUNKNOWNや0へ置換しない。未知の各回答に許される絵柄×案内の9通りからI/Gを作り、同じF_gを同じ組の2反復で共有した式で、予定分母の指標の限界を求める。成立した組だけへの分母縮小や、指標ごとに同じ原回答を別の値として補完することはしない。各指標の上下限は周辺的な到達範囲であり、全てが同時に達成できるとは限らない。信頼区間ではない。

## 7. 終了とチェックポイント

予定72枠の完走、構造欠測に伴う依存未発行を含む閉鎖、または輸送・上限停止のいずれでも一巡で閉じる。原本・失敗・形成ゲート・指標・usageを保存し、符号にかかわらず報告する。

**IS01＋このIS02の2本で一度グランドデザインへ戻る。** 同じ形式の第3小試験へ自動移行しない。

- 両立が成立したら：外から与えた固有情報を利用する能力から、本人の過去判断の維持・妥当な更新へ進むために何が不足しているかを整理する。同じ容易な課題を大規模化する理由にはしない。
- FACTSは成立しDIALOGUEで下がったら：どの組・時点で、事実の利用と他者の判断への接触が食い違ったかを固定したまま記述する。その場で記録配置を直して再実行しない。
- 形成が未成立、または測定が不成立なら：その箇所を残し、課題・受け口・指標のどれを直す必要があるかをチェックポイントで決める。人格の消失や共有の不可能とは認定しない。

HISTORY-STABILITY-02の再開か、新しい問いの確認試験へ予算を向けるかもこの時点で検討する。旧研究・旧データの意味や符号を本案に合わせて書き換えない。

## 8. 推奨案と保留する枝

推奨はこの**72要求・3条件**。本人だけの基準と完全な観測事実の基準を両方置くため、形成過程と入力情報量を混同しにくい。

形成24＋SELF/DIALOGUEだけの32＝56要求案は16件節約できるが、会話に追加事実が入る効果を分けて読めないので保留。長さを揃えた記録、誤帰属操作、反証イベント、無交流の形成枝は、因果機序をさらに分ける必要がチェックポイントで確認されたときの候補とし、今回は足さない。完全自発的な犬派／猫派の形成は、初期差の作り方そのものを対象とする別問題として残す。
