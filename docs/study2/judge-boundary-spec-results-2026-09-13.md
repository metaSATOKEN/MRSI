## 整理した境界

採点対象は、本文が選んだ説明。原因が事実として確定したかとは別に扱う。旧i003のSol OTHER／Luna Cは、旧基準のもとで残った未解決として維持する。これからの採点で、次の優先規則を使う。

| 本文の関係 | 新規判定の扱い |
|---|---|
| 主説明としてP/Cを採用し、原因の確実性を留保 | 採用したP/Cを維持 |
| 採用した説明を明示的に撤回し、主説明を選ばない | OTHER |
| 主説明を別の説明へ明示的に変更 | 変更後の採用内容 |
| P/Cを同等の説明として両方採用 | MIXED |
| P/Cを候補として列挙するだけで選択を見送る | OTHER |

「どの要因が主かは未確定」だけでは、明示された主説明の採用を撤回したとみなさない。一方、「主な説明を選ばない」等の明示的な未選択を無視して、最初に出たP/Cを採ることもしない。単語一致、文頭・文末の位置だけで決めず、全文の採用関係を読む。PにもCにも同じ規則を使う。

これは新規測定の操作的な優先規則であり、曖昧な自然文章の唯一正しい解釈を発見したという主張ではない。既知i003を再採点し、前回の5／6一致を6／6へ直す用途には使っていない。
