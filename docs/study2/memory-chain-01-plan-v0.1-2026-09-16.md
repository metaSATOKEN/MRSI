# MEMORY-CHAIN-01 — 観測を保護する保存と、書き直す保存の3段階比較

2026-09-16 / v0.1 / **DESIGN_DRAFT_OFFLINE_CHECKED**。略称MCHAIN01（MEMORY-CARRY-01のMC01と区別）。ユーザーの「次の実験設計に進もう」に沿う設計・合成点検・記帳。研究モデル要求0、認証疎通0、取得器未接続。

**最初に持っていた本人情報を、メモを引き継いで仕事を続けても使えるか。相手の情報と混ぜず、新しい証拠が出た部分は更新できるか。** 本人の観測をそのまま保護する方式と、観測もLLMが毎回書き直す方式を、同じ初回経験から3段階で比較する。4組・2役・2反復、共通初回16＋分岐後64＝**80新回答案**。

## 1. 文系向けの見取り図

Aの担当客は犬、Bの担当客は猫を希望している。最初は紙の案内が全員へ届く。途中でデジタルに変更する必要が出て、その次もデジタルが適切な状態が続く。

| 段階 | する仕事 | 見たいこと |
| --- | --- | --- |
| T1：共通の出発点 | 保存済みの本人観測・相手表明・自分の過去判断を読み、今回の決定と次回メモを返す | 出発時の回答と、最初の書き継ぎを全件残す |
| T2：案内を変える | T1から引き継いだメモと今回の新しい案内情報を読む | 犬猫の希望は保ち、案内を変更できるか |
| T3：変更後を維持する | T2から引き継いだメモと今回の案内情報を読む | さらに持ち越し、案内を不要に戻さず使えるか |

材料によって紙→デジタルとデジタル→紙を反転する。段階としては「初期と同じ→初期と反対→その変更後を維持」。T3でも今回の観測を示すため、交互に選べば正解になる設計ではない。

比較する保存方式は2つ。

| 方式 | 本人の過去観測 | 相手の過去表明 | 自分の前回判断 |
| --- | --- | --- | --- |
| **PIN：観測を保護** | 前回の自分の保存先から、そのままコピー | LLMが提出した次回メモへ置換 | 今回実際に出した判断をそのまま保存 |
| **REWRITE：観測も書き直す** | LLMが提出した次回メモへ置換 | 同上 | 同上 |

両方式ともLLMに同じ形式の次回メモを書かせ、モデルには方式名を渡さない。違うのは、保存するときに本人観測を前回の保存先から保護するか、提出された書き直しを採用するか、という1か所。PINでも書き直し案は原文のまま記録する。

「保管箱に正しい値が残る」はPINの実装上の性質なので、それ自体をLLMの能力の証拠にしない。主に測るのは、**次の回答で、その情報を使いながら自他分離と更新を両立できるか**である。

## 3. 初期記憶と真値

IS02の既知4組・2材料をすべて使い、各組のA/Bに別の保存先を作る。ME01で成功／保留した入力による選抜はしない。新しい集団形成は行わない。

| 枠 | 元データ | 最初の保存内容 |

| peer_statement | その役が受領していた相手のIS02 R1判断 | speaker、subject、animal、source_ids |

観測・相手表明を上記の小さな固定カラムへ写すのは研究側の初期化で、LLMが自発的に記憶を形成した結果ではない。対象情報は犬猫の希望に限定し、自由要約や任意の知識保存は今回扱わない。

採点の真値は初期の原観測・元発言・各時点の案内観測から固定する。書き直したメモが間違っていても、採点の真値をそれに合わせて変更しない。相手欄で答える対象は、**相手が初期の受領記録で最後に表明した絵柄**。相手の現在の希望や今回の判断を知っているか、という課題ではない。

## 4. 共通初回からの分岐と持ち越し

各組・役・反復のT1は一度だけ生成する。同じT1出力を、PINとREWRITEの両分岐で使用する。T1が異なることによる比較のずれを避け、16要求を共通化する。初回成績の良い組だけを採用しない。

状態更新は次の通り。

```text
T1入力の保存メモ M0 → T1の判断 D1 と書き直し案 W1
  PIN     : M1 = {M0の本人観測, W1の相手表明, 実際のD1}
  REWRITE : M1 = {W1の本人観測, W1の相手表明, 実際のD1}

T2入力の保存メモ M1 → T2の判断 D2 と書き直し案 W2
  各分岐で同じ規則を適用してM2を作り、T3へ渡す。
```

PINは初期原票を再読して補充せず、その分岐の直前に実在する保存メモから本人観測をコピーする。コピー元の破損を原票から復旧して続行することはしない。書き直し案と適用後の状態を別に残し、保護で何が防がれたかを後から見られるようにする。

previous_judgmentには、LLMが別途要約した判断ではなく、今回実際に返したdecisionをそのまま格納する。本人観測が壊れても過去判断から回答できる可能性を残し、観測欄の脱落だけで現在回答も失敗したと決めつけない。

相手の過去表明は両方式で書き継ぐ。今回の新しい相手発言は追加せず、T2以降に元の相手記録を再掲して救済もしない。新しい相互会話による共同状態の形成は今回の対象外で、**既存の共同経験を参照する2役の短い継続**を測る。

毎回新規文脈で、直前の保存メモと今回の案内観測だけを渡す。全会話履歴・初期原票・別条件や別反復の出力は足さない。T3の次回メモも保存して点検するが、T4は実行しない。

## 5. 何を変え、何をそろえるか

共通指示、入力カラム、出力カラム、本人希望、相手の初期表明、各時点の案内観測は全方式で同一。方式名、仮説、正答、組番号、反復番号を生成モデルへ渡さない。メモ内容が同じならPIN／REWRITEの同時点入力も同じbytesになる。

今回の因子は本人観測欄への書込み権限。PINでも相手欄と自分の判断は動く。全部を正答に固定する比較ではない。ただし、LLMの書込み案が正しく、両方式の状態が同じままなら、保存方式による実際の入力差は生じない。差が生まれた枝の数も報告し、入力が同じ枝で生じた回答差を保護の効果と断定しない。

共有の今回観測は各段階で両役分をそろえる。案内の更新に古い共同経験が必須という設計ではなく、過去判断が存在しても今回の証拠を使えるかを見る。長いメモの蓄積、容量制約、意味検索や圧縮、矛盾した本人希望の解決はまだ試さない。

## 6. 規模と順序

4組×2役×2反復の共通T1が16回答。T2/T3は各々4組×2役×2方式×2反復＝32回答。合計80要求、保存方式ごと8本の組単位の軌跡／16本の役単位の軌跡になる。

同じT1を二重に独立標本として数えない。各方式の3段階表には共通T1を参照してよいが、48＋48＝96を実生成数とは呼ばない。基になるのは4組・2材料であり、80独立群ではない。

第1反復はT1の8枠→T2の16枠→T3の16枠。各段階内の順序をseed 2026091606で混ぜる。第2反復は各段階内の順序を逆転し、同じ順序の段階をたどる。seedは提示順の固定用で、モデル生成の乱数を固定するものではない。両反復を通じて要求上限と時計をリセットしない。

第2反復は初期状態からの別軌跡。T1の入力は同一だが、T2以降は前段の回答に依存するため、ME01のような「同じbytesの反復」ではない。率の反復差を記述し、確率的な揺れと時間効果の完全な分離は主張しない。

## 7. 出力・保存の受け口

トップレベルはdecisionとnext_memoryの2欄。decisionは既存6欄、next_memoryはself_observationとpeer_statement。観測枠はobserver/subject/animal/source_ids、相手枠はspeaker/subject/animal/source_idsを持つ。完全な指示と例 (see the evidence index)。次の接続準備で、この仕様に沿う受け口と保存処理を実装する。

人物はA/B/UNKNOWN、絵柄はDOG/CAT/UNKNOWN、案内はPAPER/DIGITAL/UNKNOWN。根拠・来歴は長さ0〜8の文字列配列で、各IDは英数字・ハイフン・アンダースコアの1〜64文字。空配列は有効。所定キーの不足・余分・重複、型・列挙外、JSON外の文、サイズ超過は構造不備。UNKNOWNや意味的誤りを構造不備にしない。

直接提示カードIDはS0/P0/D0等と、今回観測N1A/N1B等。source_idsは元のM7/M9/T等の来歴を引き継ぐ欄。直接引用と来歴を混同しない。未提示ID・重複ID・誤った対象人物・本人欄への相手値等は記録するが、意味の誤りを門番で拒否したり再生成したりしない。両方式とも相手欄の意味的誤りはそのまま次へ渡す。PINの本人観測保護は事前の保存介入として別記する。

JSON全体を厳密に読めた場合はdecisionとnext_memoryの構造を独立判定する。decisionだけ有効なら、その段階の回答は採点に残す。後続に必要な片方でも構造不備なら、その役の後続枠をDEPENDENCY_UNISSUEDとし、埋め直しや前回への巻戻しをしない。共通T1の不備は両方式のその役の子孫に及ぶ。他の独立した役・枝は予定どおり続ける。JSON自体が読めない場合、切れ端からの救済はしない。

保存・取出し・送信の不一致、輸送失敗・部分応答・timeoutは研究上のメモ脱落と混ぜず、全体の取得を停止する。構造不備、輸送失敗、依存未発行、上限等での未発行、内容上のUNKNOWNを分けて数える。

## 8. 主指標・予想・終わり方

本人希望に一致をX、相手の初期表明に一致をO、今回の正しい案内をGとする。同じ回答の全3成立TRI=X×O×G。同じ組・反復・時点・方式で両役のTRIが成立したものをJとする。各分岐時点は16回答／8組反復。

**主指標ΔJ3=J_PIN,T3−J_REWRITE,T3。事前予想はΔJ3>0。** 「保護により最終段階の両立が高くなる」という厳しい予想を置く。PINの保存値が正しいだけでは達成としない。p値・信頼区間・非劣性・同等性の認定は行わず、全セルと記述値で閉じる。

| 観測結果 | 固定する読み方 |
| --- | --- |
| ΔJ3>0 | 今回の保存介入で最終の両立が高い記述結果。初期化・構造化・小標本の限界を残す |
| 両方式が全件でき、ΔJ3=0 | 3段階では保護の上積みを観測しなかった。予想は外れ。長期同等性とは言わず終了 |
| 両方式とも低く、ΔJ3=0 | どちらも今回の継続を十分支えなかった。0差を成功としない |
| ΔJ3<0 | 予想と逆。結果を修復せず保存し、固定した内訳から点検する |
| 書き直し案が正しく、両方式への入力差がほぼ生じない | 保護が働く機会の少ない試験だったと報告。誤りが出るまで延長しない |
| 欠測で符号や率が定まらない | 観測不足として範囲を示す。欠測を保留や誤答へ変換しない |

80枠で一度閉じる。T4以降の追加、難度を上げての再走、条件や正答の事後変更をしない。
