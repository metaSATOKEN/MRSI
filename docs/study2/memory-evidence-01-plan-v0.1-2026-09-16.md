# MEMORY-EVIDENCE-01 — 記録を読めることと、現在判断に使えることを分ける

2026-09-16 / v0.1 / **DESIGN_DRAFT_OFFLINE_CHECKED**。ユーザーが了承した次テーマの実験設計。研究用モデル要求0、取得器未接続。

**同じ記録を渡しても、「昔、何が記録されたか」と「今、何を選ぶか」は別の課題になる。本人の過去観測を残すことで、後者をどれだけ支えられるかを調べる。** 観測／判断／両方の3記録と、読取り／利用の2課題を別の呼出しで比較する。96種類の入力を各2回、192回答の探索案。

## 1. 直前の結果から引き継ぐ問い

[MC01](memory-carry-01-results-v0.1-2026-09-16.md)では、原票ありの本人情報は16/16、過去判断だけでは7/16が一致し、9/16がUNKNOWNだった。相手の絵柄を本人欄に入れた例は0。相手読取りと今回の案内判断は全48件正答。保存・取出し・実提示は照合済みで、記録が届かなかったための保留ではなかった。

ただし、MC01では自分の過去判断をそのまま読み取れるかを尋ねていない。「自分が何を選んだかを読み取れなかった」と「その選択を今回の希望の証拠として十分と扱わなかった」は未分離である。今回はこの違いに近づく介入を新しく行う。旧9保留の原因を特定したことにはせず、MC01の主E_CARRY=0.25や予想の外れは変更しない。

研究全体では、個体の経験と判断をどう保存すると、他者と協調しつつ本人固有の情報を使い続けられるか、という設計原理の一部に当たる。犬猫は担当予約者の希望で、主体自身の価値観や人格ではない。

## 2. 保存するものと比較条件

既知のIS02全4組・2題材・24形成原文を利用する。全組の両役を使い、MC01で正答／保留した組だけを選ばない。新しい形成は行わず、独立再現とは呼ばない。

各担当者の保存先には、自分r0/r1/r2と当時受領した相手r0/r1に加え、**本人が実際にR0入力で見た予約票本文**を保存可能にする。計8保存先。観測本文は当時の入力原文と突合し、研究者が結果を見て作った要約や新しい観測へ置き換えない。

| 条件 | 自分の過去観測 | 自分の過去判断 | 相手の過去判断 |
| --- | --- | --- | --- |
| JUDGMENT | なし | r0/r1/r2の3件 | 受領済みr0/r1の2件 |
| OBSERVATION | 予約希望の観測1件 | なし | 同じ2件 |
| BOTH | 同じ観測1件 | 同じ3件 | 同じ2件 |

観測には観測者・絵柄の対象担当者・過去の時点、判断には発言者・対象担当者・時点を付ける。保存先の持ち主と内容の対象を分ける。観測の直接提示IDはM7/M9、判断はT1〜T6。元のQ7/Q9との対応はモデルへ渡さない来歴表に保存する。相手R2、相手の予約票本文、MC01/PU01の実回答は混ぜない。

全条件で相手記録は同じ。BOTHから本人観測だけを外すとJUDGMENT、本人判断3件だけを外すとOBSERVATIONになる。観測を先、判断をその後に置き、判断内の順序は既存の提示順を保持する。全対象を決定論的に読み出し、意味検索・要約・記憶更新を入れない。

これは**情報内容・形式・件数・長さを含む保存パッケージの比較**である。観測1件と判断3件なので、純粋な「観測」というラベルだけの効果とは言わない。BOTHも単独条件より長く、冗長性・位置の差を含む。観測全文の保存は原票のコピーを使う方式であり、原票再掲と同じ内容を入力へ戻す。その内容を当時の経験からたどれることは確認するが、自律的な記憶形成や圧縮の成功とは扱わない。

## 3. 同じ記録への二つの問い

| 課題 | 本人欄で答えること | 確かめるもの |
| --- | --- | --- |
| READ | 自分の保存記録に明記された絵柄。観測なら希望されたもの、判断なら選んだもの | 記録内容の読取り |
| USE | 今回、自分の担当予約者へ渡す絵柄 | 記録に基づく現在の選択 |

**READとUSEは完全に別の新規呼出し**。READの答えをUSEに渡さず、同じ呼出しで両方を尋ねない。同一役・状況・記録条件で、入力の「本人欄への問い」だけを変更し、共通指示・背景・保存内容・今回の観測・表示順・出力形式はそろえる。

READの具体的な問いは「記録に明記された絵柄。複数記録が一致するならその絵柄、食い違うか不明ならUNKNOWN」。今回使う本人記録は、元観測と全判断の絵柄がすべて一致する。矛盾解決の試験ではない。USEは「今回渡す絵柄を担当予約者の希望に合わせて選び、判断できない場合はUNKNOWN」。

両課題で、相手欄には「相手が受領済み判断記録中で最後に表明した絵柄」、案内欄には「今回の両担当範囲に届く方法」を答える。後者はREADでも現在判断であり、READは本人欄だけの操作を指す。

MC01同様、本人の予約希望・担当は変わらないと明示する。共通案内は今回観測N3/N8から判断させ、以前と同じ方法が適切なSTABLEと、反対へ変更すべきSWITCHを比較する。STABLE／SWITCHは今回観測だけを変える。

過去判断の正しさを保証する文や、UNKNOWNを禁止する文は加えない。「過去の判断を現在の観測へ置き換えない」という共通指示も残す。その指示と問い方の下での結果であり、証拠として扱う規則自体の効果は今回は分離しない。

## 4. 規模・反復・順序

**4組×2役×2現在状況×3記録条件×2課題×2反復＝192新回答**。異なる指示＋入力は96通りで、各々を同じbytesで2回生成する。新形成0、採点LLM0。

第1波96件をseed 2026091605で混ぜ、第2波はその入力順を反転する。両波ともREAD/USE・記録条件を混在させる。これにより各入力の早い／遅い提示を対にするが、時刻の影響を完全に排除したとはしない。前の波・他条件・他反復の応答は次の要求へ入れない。反復は時間経過を経験する主体ではなく、同じ入力からの別生成である。

2反復は、1回だけの保留を安定した差と決めつけないための最低限の点検。十分な統計力の保証ではない。集計は記録×課題ごと32回答、状況を分けると16回答。基になるのは4組・2題材であり、192独立群や32独立材料として扱わない。

## 5. 主指標と予想

各記録条件cについて、READの本人正答率をR_c、USEをU_cとする。どちらも正答ラベルは既存の観測・判断と一致する犬／猫だが、課題が求める意味は異なる。

**主D＝（U_OBSERVATION − U_JUDGMENT）−（R_OBSERVATION − R_JUDGMENT）**。

言葉で言えば、「観測記録に替えたときの改善が、読取りより現在判断で大きいか」。RとUはすべて予定32回答を分母にする。主予想D>0、補助予想U_OBSERVATION−U_JUDGMENT>0かつR_JUDGMENT−U_JUDGMENT>0を固定する。

| 出方 | 読み方 |
| --- | --- |
| 判断記録のREADは良くUSEで保留が増え、観測でUSEが改善 | 記録を答えることと現在選択への利用の間に課題依存の差がある、という仮説と整合する |
| 判断記録ではREADもUSEも同程度に低い | 読取り・提示の問題と利用段階の問題をまだ分離できない |
| OBSERVATIONのREADだけ悪化してD>0 | 利用改善の裏付けにはしない。Dの符号だけで成功判定しない |
| すべて全件正答でD=0 | 予想した利用差は、この設定では観測されなかった。MC01の原因解明済みとは言わない |
| 観測記録でもUSEで保留が多い | 観測保存だけで解決するという予想を支持しない。事後に指示を強めて救済しない |

BOTHは補助比較としてU_BOTH−U_OBSERVATIONを報告する。観測と判断を一緒に残したときの上積み・干渉を見るが、差0で同等性を認定しない。Dと補助差に事後の成功率閾値、p値、信頼区間を置かない。探索的な記述値として全セルとともに閉じる。

別々の生成でREADが成功しUSEが保留しても、「同じ応答の内部では読めていたのに拒否した」という証明にはならない。内的記憶や判断理由を特定せず、**二つの問いへの出力差**として扱う。READ成功例だけを選別してUSEの分母にする解析はしない。

## 6. 副指標・出所・欠測

記録×課題×状況の全12セルで、本人正答X、相手表明正答O、今回案内正答G、同一回答の全3成立TRI、同じ組・状況・課題・記録・反復で両役が全3成立したJを報告する。各セルは16回答／8組反復。3欄それぞれのUNKNOWN、本人欄への相手絵柄、旧案内も別計数する。READのX/Jを現在の本人希望の適切な利用率と呼ばない。

材料別・組別・反復別の主Dと率を示す。2反復の選択一致は本人・相手・案内の各欄と3欄全部を96対で示す。出所配列の一致は別に示し、順序の一致とID集合の一致を区別する。欠測対と観測可能対を併記し、欠測を不一致にしない。

6欄JSONはMC01と同じキーと列挙型を使う。構造不備は不足/余分/重複キー、型・列挙外、JSON外文、回答サイズ超過。意味的に望ましくない選択やUNKNOWNは有効回答である。判断記録だけでの保留が証拠に慎重な応答である可能性も残し、世界設定との不一致を即座に故障へ読み替えない。

出所はM（本人過去観測）／T（過去判断）／N（今回観測）を分け、利用不能・重複・UNKNOWNで根拠あり、本人欄で相手記録、相手欄で本人記録、具体的案内に今回観測なしを別記する。フラグで正答点を変更しない。引用の意味的十分性・モデル内部の参照先は未評価とする。

欠測・未発行・輸送失敗はUNKNOWNへ埋めない。本人3択×相手3択×案内3択の27応答候補から、同一回答の整合性と両役のJを保ち、固定分母の周辺到達範囲を計算する。主Dは4つの異なる応答セルの符号付き和で、全欠測なら[-2,2]。各指標の全端点が同時に成立する保証はなく、信頼区間ではない。欠測出所のフラグは推定補完しない。

相手r0/r1の絵柄は同じなので、最新の異なる主張を選び分ける能力は今回も測れない。また、相手情報しかない条件や新しい原票を渡す条件は今回追加しない。MC01を新試験の同時対照として差し引くこともしない。
