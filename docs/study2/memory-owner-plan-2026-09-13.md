# MEMORY-OWNER-01：同じ履歴で「自分の記録」の所在を変える

2026-09-13。状態：設計・ローカル準備。ユーザーの「次の実験の設計」に対する具体案。新規モデル実測は未発行で、最後に示す32セッションの範囲を実行前に提示する。

Meteonから参考にするのは、**記憶の本文と、その記録の所在を別に持つ点だけ**。単騎の人格構成・誤帰属の検品・出力修正は導入しない。元のSEED-INTERACTION、オフライン監査、Meteon参照メモは当時の記録として保持する。

## 問い

同じ6発言を同じ順番で読んでも、どの役の発言を「自分の過去の発言」として渡すかによって、現在選ぶ説明のP/C方向は変わるか。

直前の会話／自己履歴比較では、他者の有無と一緒に情報量が変わった。今回は全条件に同じ6発言を渡し、自己の所在だけを変える。記憶は入力に与える明示的な記録であり、常駐個体の内部記憶や人格の存在を前提にしない。

## 固定材料と条件

元run `study2/runs/seed-interaction-prepared-20260913` の**全4組**を用いる。各組についてr0のA/B/Cと会話枝INTERACTのr1のA/B/C、計6原出力を使う。全24原出力を新runへhash付きで複写する。自己履歴枝とr2は材料へ含めない。r1は最初の他者接触後の状態で、その後の一段応答を調べるために固定した。P/Cで良い組や発言だけを選ばない。

これは**既知の結果を使って設計する、新規応答による機序探索**。既存材料に対する独立な確認試験、未見の4集団、形成ゲート通過とは呼ばない。過去のラベルや説明を新しい応答数へ合算しない。

新しい回答者の役は常にメンバーX。他者名はY/Zで、いずれも1文字の名前だけを使う。元のA/B/Cは研究側に保存する出所IDであり、回答者には知らせない。

| 条件 | 自分Xに割り当てる原発言 | 他者Y/Zの割付 | 1組あたりの新規回答 |
| --- | --- | --- | ---: |
| OWN_A | Aのr0とr1 | B/C→Y/ZとZ/Yの両方 | 2 |
| OWN_B | Bのr0とr1 | A/C→Y/ZとZ/Yの両方 | 2 |
| OWN_C | Cのr0とr1 | A/B→Y/ZとZ/Yの両方 | 2 |

原A/B/C→表示X/Y/Zの**全6置換**を各組1回ずつ使う。4組×6置換＝24新規回答。他者名の2配置は、追加の独立集団や同一プロンプト反復ではなく、他者の名前の割付を平均するための配置反復である。

具体例：原文の並びは常に `[r0-A, r0-B, r0-C, r1-A, r1-B, r1-C]`。表示上の発言者だけが `X,Y,Z,X,Y,Z` → `Y,X,Z,Y,X,Z` のように変わる。自己発言が先頭になるように並べ替えない。r0からr1まで同じ人物の対応を保つ。各入力に自己2発言、他者4発言があり、各原出力は6条件で各1回ずつ提示される。

**24原文の本文・preference・記号・空白はbyteで不変**。語句・一人称を研究者が書き換えず、表示名は原文の外の発言者見出しだけで操作する。候補原文全24には元のA/B/Cを指す役名表現がないことを目視確認した。実際の生成元、実験上の表示名、raw SHA、入力内位置を別々に記録する。

同じ組の6入力は文字数・UTF-8 byte数が等しく、発言者見出しのX/Y/Zを中立記号へ置換すると全文が一致することを検査する。モデルの実トークナイザでの同一トークン数までは保証しない。自己ラベルが付く位置の効果も含む操作であり、文中位置から独立した「所有感」の純効果とはしない。

共通生成指示と犬猫の選択肢は既存版を使う。役だけXへ統一する。出来事欄も前回の後続入力と同じ冒頭＋「これは前の記録と同じ出来事です。追加の観測事実は提示されていません。」とし、原事象の手掛かりを新たに再掲しない。P/Cの支持・同調・自分の過去との一貫性を指示しない。誰の発言かを質問する追加課題も設けない。

## 主要な記述比較

新しい説明は既存のP/C/MIXED/OTHER/UNSCORABLE指示でSolとLunaが各1回採点する。スコアはP=+1、C=−1、MIXED/OTHER=0。MIXEDとOTHERの件数は別々に残す。

各組f・自己の原役jについて、他者名の2配置の新規スコア平均を `μ(f,j)` とする。元のr1で最もP寄りの役集合をH、最もC寄りの役集合をLとし、同点の役はすべて等重みで平均する。H/Lは元の固定票から新規発行前に定め、出力を見て変えない。

`Δ(f) = Hの役を自己としたμの平均 − Lの役を自己としたμの平均`

**主要記述値 `Δ = 全4組のΔ(f)の等重み平均`**。範囲は−2〜+2で、割合や百分率ではない。正なら、元の直前説明がP寄りの役を自己にした条件ほど、新しい説明もP寄りだったという方向差。現在のframeと、自己として与えた直前のframeの対応を見る値である。

| 元組 | 元r1のA/B/C（Sol） | 元r1のA/B/C（Luna） | H：P寄り側 | L：C寄り側 |
| --- | --- | --- | --- | --- |
| F01 | P / C / P | P / C / P | A,C | B |
| F02 | MIXED / P / MIXED | MIXED / P / MIXED | B | A,C |
| F03 | C / P / C | C / OTHER / C | B | A,C |
| F04 | C / P / C | C / P / C | B | A,C |

F02のLはMIXED、F03のHはLunaではOTHERであり、全組が純粋なP対Cではない。両採点法のH/L集合は今回同一だが、元票のsi021 P/OTHER不一致を消したことにはしない。全4組の内訳、全3自己条件の平均、カテゴリ数、他者名2配置の差、犬猫選択を併記する。後からF02を除く等の主解析変更はしない。

予想は `Δ>0`。ただし次の語は記述方向の名称で、統計的な検出・成功判定ではない。

- 両採点法のΔ>0：`SELF_DIRECTIONAL_ASSOCIATION`（自己として渡した直前説明と同方向）。
- 両採点法のΔ<0：`OPPOSITE_DIRECTIONAL_ASSOCIATION`（反対方向）。
- 両採点法のΔ=0：`NO_NET_DIFFERENCE`（この平均で差0）。
- それ以外：`RATER_DEPENDENT`（採点法で符号・ゼロ判定が揃わない）。

ゼロは同等性、正値は有意差や因果機序の確定を意味しない。各セル1応答、各自己条件は異なる他者名配置2応答で、生成のばらつきも含む。全4組は共通材料・モデル由来の固定刺激であり、母集団の独立4標本ともみなさない。p値・検出力・信頼区間・NPP値は今回計算しない。方向に応じた追加Nや途中停止もしない。
