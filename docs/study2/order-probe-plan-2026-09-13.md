# ORDER-PROBE-01：M1の提示順を新規標本で点検

2026-09-13。ユーザーの「terraは温存」「方針OKなのでGO」を、直前に提案したM1の提示順への敏感さを切り分ける実行承認として受領。今回の通常の実装判断で小さい固定試験へ具体化し、同じGOは取り直さない。最初の研究発行前に本計画・事前カード・材料参照・割付・解析を固定する。

## 固定標本と割付

生成は各提示順12、合計24新規セッション。同じ役・同じ反復のPC/CPを一対とし、3役×4反復＝12対を作る。各対の2枠を一緒に発行し、両方が完了するまで次の対を発行しない。モデル側の乱数seedを一致させた対応ではなく、役と実行時期をそろえた割付ブロックである。

対の実行順は固定seedによるシャッフル。各対で先の枠をPCにするかCPにするかを、OS乱数から一度だけ得る12ビットで独立に決め、全24入力の作成時に保存する。結果に応じて乱数を引き直さない。各対にPC/CPが一つずつなので、全体では必ず各12になる。先発枠のPC/CP数の一致は追加条件にしない。

採点は6説明×4組を両モデルへ渡す計8セッション、48評価。各組は同じ反復の3役×PC/CPを含み、各順3件、各役2件。組内の匿名順と採点発行順は、提示順割付の乱数とは別の固定seedで作り、生成結果も提示順の割付値も見て調整しない。両者には同一byteの組を別セッションで提示する。

採点者には材料名・生成の提示順・役・反復・犬猫選択・他の票を示さない。事象は前回同様にPC順で統一する。今回は**生成側の提示順**を比較し、採点者自身の事象順序の効果は切り分けない。

## 主要指標と検定

Sol/Lunaを別々に集計する。Pを+1、Cを−1、MIXEDとOTHERを0とする方向スコアを使用し、各対の `d = score(PC) − score(CP)` と、その12対平均Δを計算する。Δ>0は希望を先に書く方が相対的にPへ寄る向き。MIXEDとOTHERは方向スコアだけを0とし、カテゴリ別件数・全予定分母・P/C coverageは分けて報告する。どちらも欠損へ置換しない。

完全観測の場合のみ、12対の枠内割付を反転する全2^12＝4096通りを列挙する。統計量は `|sum(d)|`、観測値以上を含む両側の正確な割付検定とし、同点・d=0の対も全4096分母に含める。Monte Carlo近似や途中のp値点検をしない。基準は両側0.05、比較は整数分子・分母で行う。

これは、各対の独立な無作為割付と、隔離した生成・盲検採点によって割付以外の条件を保てることを前提に、割付によるスコア変化がないというsharp nullを調べる検定。採点モデルを人間の独立標本と数えず、結果の適用範囲は今回の固定材料・役・モデル・呼出し手順とする。母集団への一般化、生成モデルの同一seedによる対比較、集団内増幅、NPPの検定ではない。

全24生成・48評価を固定した後、一度だけ次で判定する。

- **DETECTED_ORDER_SENSITIVITY**：完全観測で両モデルともp≤0.05、Δの符号が同じで0でない。共通の方向を明記する。片方だけで採択しない。
- **NO_CLEAR_ORDER_SIGNAL**：完全観測で両モデルともp>0.05。無影響・同等性・十分な検出力の証明とはしない。
- **INCONCLUSIVE**：どこかに欠損／UNSCORABLE／経路不成立がある、または片方だけが有意、あるいは両者で方向が逆。欠損があれば主要p値は両者ともNAとし、完全対だけに分母を減らさない。

前回の傾向に合わせて片側検定にせず、逆方向の差も同じ両側検定で認識する。二つの採点法が両方とも検出するという交差条件であり、都合のよい採点者の選択・平均・多数決は行わない。材料選定ゲートとは別の判定で、検出・非検出を理由に前回のNO_BALANCED_CANDIDATEを変更しない。

固定24応答は小さい追試の作業量として選ぶ。検出力保証は付けない。群数・有意になるまでの追加N・採点修復・Terraの途中投入は0。
