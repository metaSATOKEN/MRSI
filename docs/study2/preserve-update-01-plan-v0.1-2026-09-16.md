## 1. 今回の問い

**自分の担当者情報は守りながら、以前の共通判断が古くなったら、新しい証拠に合わせて変えられるか。**

IS02では、部分観測の交換後に4/4組が本人の絵柄と共通案内を両立した。しかし、次回も予約希望・環境条件が同じで、判断履歴を外しても正答できた。そこで今回は、本人情報を固定し、共通案内の条件だけを変える。

例えば、Aの担当予約者は犬、Bは猫のまま。過去は紙の案内が全員に届いた。次回の直前試験では、紙が一部に届かず、デジタルが全員に届くことが分かった。このとき、犬／猫の違いを保ち、共通案内だけデジタルへ更新できるかを見る。

同時に、次回も紙が全員に届く条件を置く。常に過去と反対の答えを出すだけでは、こちらで誤る。これにより「何も変えない」「何でも変える」「変えるべき部分を変える」を分ける。

今回も犬猫は予約者の希望であり、主体自身の価値や人格ではない。本人の予約票を毎回提示する。原票なしで本人の過去を保持すること、自発的な選好形成、長期共存はこの試験の対象外。

## 2. 同じ過去から4条件へ分岐する

IS02の2題材・反転2設定、**全4組のr0/r1/r2・全24原文**を、そのまま用いる。4/4の成立を既に知ったうえで設計する探索的な後続試験であり、未使用の形成標本による独立再現とはしない。新たに良い組だけを選んだり、形成をやり直したりせず、IS02のプローブ原文は投入しない。

| 今回の観測 | FACTS：原観測のみ | HISTORY：原観測＋過去の判断 |
| --- | --- | --- |
| STABLE：以前と同じ方法が全員に届く | 16回答 | 16回答 |
| SWITCH：反対の方法が全員に届く | 16回答 | 16回答 |

全条件に、本人の予約票、双方の過去の原観測票、双方の今回の原観測票を渡す。**同じ最新状況内では、HISTORYとFACTSの原票は完全に同じ。** HISTORYだけ、両役の過去の6判断を原文のまま加える。STABLEとSWITCHの違いは今回の原観測票だけにする。

FACTSには本人のr0判断も入れない。IS02のFACTSには本人r0があったので、同じ名称でも入力定義が異なる。新試験内の比較で評価し、IS02の成績と差し引いて履歴効果を推定しない。

各回答は新しい文脈から生成する。同じ過去から分岐する仮想の次回であり、STABLEの回答をSWITCHへ渡すような連続系列ではない。今回のA/Bの回答も互いに見せず、同じ条件・反復で両者が何を選んだかを後で組にする。

## 3. 情報不足と時点の曖昧さを減らす

本人の予約者、希望、担当範囲は変わらない。一方、案内方法は今回の受付直前の試験で両範囲の全員に届いたものを選ぶ。試験から受付まで条件は変わらないことを明示する。全条件で両者の今回観測がそろい、方法の正答は一意に決まる。

過去の観測E3/E8、今回の観測N3/N8、過去判断T1〜T6を別IDと時点で示す。過去の本文を現在の観測へ書き換えず、話者・時点・原文の対応を保持する。本人の予約票Q7/Q9は適用対象が変わらず、各役には自分の票だけを渡す。相手の発言内に私有票IDがあっても、その原票を受け取った扱いにはしない。

入力の並びは、課題・本人予約票・過去観測・過去判断・今回観測・今回の依頼で固定する。現在の観測は後方に置く。条件名STABLE/SWITCH、FACTS/HISTORY、正答、反復番号はモデルへ渡さない。

## 4. 何を数えるか

出力は既存の4欄JSON：`mascot`、`mascot_sources`、`channel`、`channel_sources`。選択は犬／猫／UNKNOWN、紙／デジタル／UNKNOWN。自由理由や追加のLLM採点は用いない。

Iは本人の予約希望との一致、Gは**今回の観測から決まる方法**との一致。OLDは以前の成功方法の選択、OTHERはそれと反対の方法、UNKNOWNは保留回答を数える。SWITCHではGとOTHERが一致し、OLDは誤った旧方法。STABLEではGとOLDが一致し、OTHERは不要な変更になる。

| 指標 | 固定した定義 |
| --- | --- |
| **主記述差U** | G_SWITCH,HISTORY − G_SWITCH,FACTS。更新が必要な場面で、判断履歴を足した差 |
| 補助B | U − (G_STABLE,HISTORY − G_STABLE,FACTS)。変化がない場面での履歴差と比較する |
| L_SWITCH | I_SWITCH,HISTORY − I_SWITCH,FACTS。更新時に本人情報の保持が崩れないか |
| ΔOLD_SWITCH | OLD_SWITCH,HISTORY − OLD_SWITCH,FACTS。更新が必要なのに旧方法を選ぶ差 |
| 各セルI/G/OLD/OTHER/UNKNOWN | 各16回答を分母に、選択の内訳を報告する |
| 各セルJ | 同じ組・反復でA/BともI=G=1の割合。各8組反復が分母 |

**U=0だけでは良好と判定しない。** 両条件とも古い方法に固執していても差は0になる。各セルの水準・J・本人情報・旧方法・UNKNOWNを並べ、次のように読む。

| 観測の形 | 読める範囲 |
| --- | --- |
| FACTSは最新観測を使い、HISTORYのSWITCHで旧方法が増える | この固定標本で、判断履歴の追加と古い方法の選択増加が対応した |
| FACTSでもSWITCHを誤る | 最新情報の理解・時点・課題設計等を点検する。履歴特有の固執とは決めない |
| HISTORYでUNKNOWNが増える | 判断保留の増加として記録。古い答えへの固執と混ぜない。原因は未特定 |
| 案内は正しいが本人の絵柄が崩れる | 更新と本人情報の保持を両立していない例として残す |
| 全条件で両立する | 明確な原票・時点・規則の下では適切に保持・更新できた。広い耐性や人格の証明にはしない |

事前予想は全4セルI=G=J=1、U=B=L_SWITCH=ΔOLD_SWITCH=0。SWITCHのOLD=0、STABLEのOTHER=0。予想が外れた場合も、その符号と内訳を保持する。p値・信頼区間や事後の成功率閾値を置かず、0差を同等性・非劣性へ昇格しない。

出所の申告では、利用可能ID、自他、過去観測／今回観測／過去判断を分ける。「特定案内を選んだが今回観測IDを挙げない」「過去IDだけを挙げる」例も数える。ただし、これだけで内部の参照先や意味的な誤帰属と認定しない。出所フラグで選択点を変更しない。
