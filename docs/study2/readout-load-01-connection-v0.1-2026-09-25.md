# READOUT-LOAD-01：Colabの1セル版・使い方

2026-09-25／接続準備v0.1。承認済みの[設計](../../experiments/RL01/docs/readout-load-01-plan-v0.1-2026-09-25.md)を実行するコード。**設定編集・Drive接続・過去ZIPのアップロードは不要。**

## 実行するもの

[Readable code and current instructions](../../experiments/RL01/generation/README.md) の**全文**を、ColabのGPUランタイムの1セルへコピーして実行する。A100 80GBまたはRTX PRO 6000 Blackwell級を想定し、モデル取得前に実VRAM・空きVRAM・BF16対応を検査する。

1. セルを実行すると、固定材料・採点器の合成点検、GPU点検、隔離したPython環境の準備を行う。
2. 固定revisionのQwen3.5-27Bを取得・ロードし、96回答を順に生成する。途中の誤答やJSON形式不備でも次へ進む。
3. 終了時に **`npp-rl01-result-日時-識別子.zip`** のダウンロードが始まる。このZIPを保管して返す。

自動ダウンロードがブラウザに止められた場合は、Colab左側のファイル欄で、表示された `/content/npp-rl01-result-…zip` をダウンロードする。別のセル、APIキー、Drive認証は必要ない。

## 途中保存・停止・二度押し

各回答を保存し、24回答ごとに途中ZIPを `/content/npp_rl01_runs/` に作る。途中ZIPの作成では停止せず、そのまま進む。自動ダウンロードは終了ZIPの一回で、途中ZIPは必要に応じてファイル欄から回収できる。

- **誤答・形式不備・長さ打切り**：原文と成分採点を残して、次の独立した回答へ進む。
- **時間上限・利用者の停止・OOM等の実行例外**：取得済みを保存し、残りを未実行として閉じてZIPを作る。開始したが回答を回収できなかったものは未確定として区別する。
- **同じランタイムでセルを再実行**：既存記録を再照合し、ZIPをもう一度返す。モデルの再ロード・追加生成は行わない。

今回は別ランタイムへのZIP復元や、中断後の残りの自動再開は設けていない。停止したら、その結果ZIPを返して次を判断する。前回の実行ロックが残る場合も、重複生成を避けて停止する。ランタイムそのものが破棄されると、未ダウンロードの一時記録は失われる。
