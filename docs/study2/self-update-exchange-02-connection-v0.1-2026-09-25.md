# SELF-UPDATE-EXCHANGE-02 — Colab一セル版の使い方・接続準備

2026-09-25／v0.1。承認済みの[二巡目の設計](../../experiments/SX02/docs/self-update-exchange-02-plan-v0.1-2026-09-25.md)を実行コードへ接続した。**Python全文をColabのGPUランタイムの1セルに貼り付けて実行する。設定編集・Drive接続・過去ZIPのアップロードは不要。**

## 使い方

1. [Readable code and current instructions](../../experiments/SX02/generation/README.md)を開き、全文をコピーする。
2. ColabのGPUランタイム（A100 80GBまたはRTX PRO 6000 Blackwell級）のコードセル一つへ貼り付けて実行する。
3. 終了時の **`npp-sx02-result-日時-ID.zip`** を保存し、このタスクへ返す。

自動ダウンロードがブラウザに止められた場合は、Colab左側のファイル欄から `/content/npp-sx02-result-*.zip` をダウンロードする。初期設定のまま研究バッチを開始する。ローカルPCでの実行は不要で、Colab以外では通信・ML importより前に停止する。

**環境準備込み60分が停止上限。** 所要時間の保証ではなく、モデルの取得・GPU・入力長によって完了時間は変わる。末尾90秒を終了処理用に確保する。

## このセルで行うこと

前回SX01の実保存32冊を同梱し、本人の新通知→実保存行の交換→古い通知→本人と共同の同時利用をもう一巡する。二人それぞれの観測が更新され、共同の案内は前回から反転する。担当客の希望は前回のノートから引き継ぐ。

| 項目 | 範囲・動き |
| --- | --- |
| 入力 | 初回32入力を固定。後続最大96入力を今回の実保存物から作る |
| 生成 | 更新96＋読み出し32＝最大128回答、自動再生成0 |
| 材料 | 既知8材料×2反復×2役×4工程。反復・役・工程を独立材料数に足さない |
| 中間保存 | 2組の経路（最大16回答）の処理ごとに途中ZIP |
| 意味不成立 | 誤りを含む受理済みノートを後続へ渡し、原案・保存後・読出しを別に採点 |
| 構造不備 | 保存不能の応答とその依存先を記録し、独立した組は続行 |
| 実行例外・OOM・時間上限 | 到達点を保存し、残りを未実施／依存欠測として閉じる |
| 最終回収 | 全128予定IDの集計・照合と、終了ZIPの自動ダウンロード |
| 再クリック | 同じ保存先があれば、追加生成・環境準備なしで再照合とZIP再返却 |
| 保存・費用 | 非公開、削除期限なし。Drive接続なし、既存Colab枠、有料API・新規購入0 |

保存先は `/content/npp_sx02_runs/self-update-exchange-02-v01/`。途中ZIPはその親フォルダ、終了ZIPは `/content` に作る。ランタイム破棄で未回収の記録は消えるので、ZIPを手元に保存する。別ランタイムでの生成再開は実装していない。

## 引き継ぎと採点

初回は元の保存ファイルと対応結果のhashを確認して読む。その後は自分の実保存ファイルを読み戻し、交換時には相手のSELF保存物の本人観測一行だけを渡す。親結果・親保存物・転送行のhashを各入力に記録する。

保存器は人物ごとに最新版を選んで観測行全体を複製する。担当客の欄はモデルが記述した内容を保持し、誤記も正解へ復元しない。READは実ノートへの忠実性と、今回の担当客・最新観測への一致を分けて数える。犬猫は実回答のanimalを採用し、共同案内は実回答の四値から計算する。

初回片方が保存不能なら、その組の交換は双方とも依存欠測になる。交換以降の片方の不備は、依存関係のない相手側を止めない。開始記録があって回答がない応答は `INTERRUPTED_UNCERTAIN` として閉じ、再生成しない。

モデル設定はQwen/Qwen3.5-27Bの固定revision、BF16・SDPA・non-thinking、入力8192／出力2048 token上限。UPDATE指示・schema・人物別最新版保存はSX01、READ指示・schemaはRU01からバイト一致で継承した。JSONは正常な裸JSONをそのまま受け、既知の完全なJSONフェンスだけ外側12bytesを除去する。原文・正規化文・前後hashを保存し、値やIDの補修は行わない。

主判定はA/B×4工程がすべて成立する16経路。14/16以上かつ各反復7/8以上を固定目安とし、欠測の上下限からMET／NOT_MET／INCONCLUSIVEを報告する。予定一巡で閉じ、結果を見て追加巡回しない。
