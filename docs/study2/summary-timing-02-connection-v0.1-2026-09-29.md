## 使い方

1. [Readable code and current instructions](../../experiments/ST02/generation/README.md)を開き、**全文をColabの一セルへコピー**する。設定編集と旧ZIPのアップロードは不要。
2. 前回と同様、A100 80GBまたはRTX PRO 6000 Blackwell級のGPUランタイムで実行する。
3. 終了後に自動ダウンロードされる **`npp-st02-result-*.zip`** を返す。自動DLが始まらない場合は、Colab左のファイル欄から `/content` 内の同名ZIPを保存する。

**Drive接続なし、基準232／最大248回答、準備込み45分上限。** 前回の実績から所要時間の目安は25分前後。準備・GPU・出力長によって変わる。

誤答や形式不備はログを残し、独立して進められる経路を続行する。親の形式不備で入力を作れない後続だけを依存欠測にする。再生成は0。

四経路・診断が閉じるごとに、途中ZIPを `/content/npp_st02_runs/` へ保存する。時間切れ・例外では保存済み記録を回収する。同じランタイムでセルを再実行すると、追加生成せず、既存記録を照合してZIPを返す。実行中のロックがあれば重複生成を拒否する。ランタイム自体が破棄された場合、未ダウンロードの一時ファイルは残らないことがある。
