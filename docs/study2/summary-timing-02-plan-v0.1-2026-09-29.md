# SUMMARY-TIMING-02 — 未使用材料でも、本人判断と共同方針を両立できるか

2026-09-29。**本人の経験集計を「最後だけ渡す／最初から渡す」二方式を、新しい8材料で比較する。指示や採点は前回から固定し、この一巡の後は結果にかかわらずチェックポイントへ進む。**

ユーザーはこの方針に同意し、次の実験設計を依頼した。今回は設計・材料と取得前規則の固定・オフライン点検・記帳まで。実行用のColab一セルは、設計確認後に作成する。

## 1. 今回、一つ確かめること

[ST01](../../experiments/ST01/docs/summary-timing-01-result-2026-09-29.md)では、途中を含めて本人判断を保てた経路がLATE 15/24、EARLY 24/24だった。この差は三つの本人形成を三経路ずつに共用した結果で、最後の利用だけなら両方式48/48だった。EARLYは共同の成否を含む運転目安にも到達した一方、最適な共同案を退ける一件は両方式に残った。

今回の問いは、**供給方法を固定したまま、この両立が未使用の数値材料でも続くか**である。比較対象は今回新しく実行するLATEとEARLY。旧ST01との差や、旧結果との合算を方式効果に使わない。

方向予想は、全工程の本人保持について **EARLY > LATE**。加えて、本人保持の改善と共同の合意・適切保留が両立するかを見る。前回の＋37.5ポイントという大きさを再現条件にはしない。今回も同じ課題形式の小比較であり、初期形成と後続での支援はまとめた介入として扱う。

## 2. 比較する二方式

| 計算資料を渡す場面 | LATE：最後だけ | EARLY：最初から |
|---|---|---|
| 本人判断を形成する FORM | 本人の経験行 | 本人の経験行＋本人集計 |
| 相手の開始案を確認する CONFIRM | 全経験＋本人の実判断＋共同候補・合計 | 左記＋本人集計 |
| 実対案を再確認する RECHECK | 全経験＋本人の実判断＋対案＋共同候補・合計 | 左記＋本人集計 |
| 二人が記録を使う USE | 全経験＋本人の実直近判断＋共同記録＋本人集計 | 同じ種類の資料 |
| 別枠の人工対案診断 | 再確認と同じ供給範囲 | 再確認と同じ供給範囲 |

本人集計は、その入力に含まれるholder本人の観測だけからコードが計算する。各媒体の成功人数合計÷試行人数合計を40人当たりへ換算し、本人の経験IDとともに添える。**推奨する答えのラベルは供給せず、LLMが本人判断を出す。** 共同候補表も二人の実経験から計算し、本人集計とは別欄に置く。

指示4種・回答schema4種・出力検査・本人/共同の採点・共同候補表の供給範囲はST01と同じ。両条件の同じ段階では、本人集計の有無を介入とする。ただし後続入力は各条件の実回答に依存するため、途中から記録や分岐も異なり得る。

N02の前回不備を狙った指示追加や、正しい本人判断・共同割付への機械的置換は行わない。生成案を採点結果で選別せず、構造として渡せる不適切な案も後続へ渡す。

## 4. 実際の記録を、一往復と次の仕事へ渡す

```text
各条件でA/Bの本人判断を新しく形成
  ↓ その条件内で三つの開始案へ分岐
最適な案／合法だが劣る案／同じ資源を二人へ割り当てた案
  ↓ 相手が確認
ACCEPT・HOLD → 二人が利用
COUNTER → 元の開始役が一度だけ再確認 → 二人が利用
```

開始案は実験者が作成する課題資料で、LLMによる自然提案ではない。各条件の16本人形成を三開始型の24経路へ共用する。旧実験や他条件の回答を混ぜない。

最適な開始案にはACCEPT。劣位・資源違反の開始案には最適COUNTERまたはHOLD。再確認は、入力された実COUNTERが最適で参照も適切ならACCEPT、それ以外はHOLDとし、対案の追加は認めない。一往復で閉じる。

USEには各役の実直近本人判断と時間順の共同記録を渡す。正式な合意があれば、その割付を使う。未合意なら共同だけ保留し、本人の仕事を続ける。USEでは共同案を再最適化しない。最後に本人正答へ戻っても、途中の不備は全工程評価に残る。

自然な対案が十分に出ない場合にも確認範囲を確保するため、N01/N04/N05/N08には最適・劣位・資源違反の人工対案を一つずつ用意する。**条件ごと12回答の診断は、本体と別集計し、後続USEを行わない。** 本人判断にはその条件の新FORMを使う。

## 5. 判定と、チェックポイントへの進み方

### 本人保持の方式差と、運転目安を分ける

主評価は、24対応経路についての**本人保持IのEARLY−LATE差**。Iは二役FORM、CONFIRM、適用時RECHECK、二役USEの全てで、本人判断と本人経験参照が適切なら成立する。本人推奨と共同担当の違いは不備ではない。

| 評価 | 対応数 | 確かめること |
|---|---:|---|
| 本人保持 I（主評価） | 24経路対 | 途中の本人判断を含めて保てたか |
| 最初の本人形成 | 16回答対 | 差が最初から生じたか |
| 本人と共同の全工程適合 J | 24経路対 | 両方の契約を全工程で守れたか |
| 合意 K/G、誤合意、保留の適否 | 24経路対 | 一往復の共同の終点はどうなったか |
| 二人のUSEと、直近本人保存→USEの遷移 | 48回答対 | 維持・回復・劣化・誤り継続を区別できるか |
| 人工対案への適合 D | 12回答対 | 本人判断・共同応答・参照を使い分けられたか |

対応結果は双方成立・EARLYのみ・LATEのみ・双方不成立・いずれか未確定の五分類。欠測なしなら差は成立数差÷固定対応数。欠測があれば各未確定を0/1に置いた保守的上下限を示し、未確定を不成立へ一律変換しない。上下限が正なら改善方向、負なら低下方向、両端0なら同率、その他は方向未確定。これは信頼区間ではなく、p値・母集団区間は算出しない。

材料ごとの三経路、開始型、本人推奨の同異、合計差、開始役を並記する。8材料から分岐した24経路と、共用した本人形成の依存を維持する。自然RECHECKは入力対案の品質別に件数を示す。条件で対案が異なる場合、その回答率を同じ入力に対する効果とは読まない。

### ST01から継承する運転目安

次段階候補のEARLYを以下で評価し、LATEにも同じ基準を併記する。

- 本体：J≥22/24、開始型ごとJ≥7/8、I=24/24、誤合意0。
- 適切合意G：最適開始≥7/8、劣位・資源違反開始は各≥6/8。
- 人工診断：本人・共同応答・参照を含むD=12/12。

本体と人工診断を別判定し、両方に届けば総合MET_IN_FIXED_SAMPLE。既知成立のみで到達ならMET、全未確定を最善に置いても未達ならNOT_MET、その間はINCONCLUSIVE。誤合意0について、有無が不明な経路は未確定とする。全保留ではGの目安を満たさない。目安はこの固定材料での工学的な進行基準である。

| 結果 | チェックポイントに残す結論 |
|---|---|
| EARLYのIが高く、総合目安にも到達 | この新材料でも改善方向と両立の運用成立を観測 |
| 両条件が目安に到達し、Iは同率 | この新材料で両方式が運用成立。早期供給の優位は未確認 |
| Iの改善はあるが、EARLYが目安未達 | 改善した所在と、残る本人/共同の不備を分ける |
| 逆方向、または両条件未達 | 方式が成立する範囲を見直す証拠として残す |
| 形式不備・中断等で未確定 | 得られた工程と、判定できなかった工程を残す |

**いずれの結果でも、この一巡を集計・照合したらチェックポイントへ進む。** 未達を理由に新材料、反復、指示修正を自動追加しない。そこで、本人判断・共同方針・確認/保留の到達点、コードが供給した資料とLLMが決めた内容、途中記録と最後の正答を整理する。次の一手は、継続期間を延ばすか、支援段階を分けるか、実行変動を測るかから改めて選ぶ。論文化の時期もそこで判断する。

## 7. 今回の保留棚

推奨はこの新8材料の二条件比較。前回と同規模・同じ契約で、既知材料からの転移を確認できる。結果を待って件数を増やすことは今回の選択肢に含めない。

| 保留案 | 今回との差・再検討条件 |
|---|---|
| FORMだけ支援する等の第三条件 | 同規模なら最大124回答程度の追加。新材料でも差が現れ、どの段階の寄与かを次の主題にする場合 |
| 同一入力の反復 | 一巡追加で最大248回答。同率や基準条件の変動が観測され、ばらつきの分離を次の主題にする場合 |
| N02型を直す指示・判断の機械的強制 | 比較契約を変える。今回も同型の不備が出た場合、チェックポイントで原因候補と対象工程を定めてから設計 |
| 新しい出来事を加える継続試験 | 後続生成が必要。本人と共同の成立条件を整理した後、更新・鮮度・帰属を何巡追うかを別途固定 |
| さらに多くの材料や別モデル | 工学的目安を母集団の信頼性へ広げたい段階で、効果量と費用を含めて別に設計 |
