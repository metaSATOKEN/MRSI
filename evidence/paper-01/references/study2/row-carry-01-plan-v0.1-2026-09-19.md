# ROW-CARRY-01 — 観測を出典ごと一行で引き継ぐ方式の小比較

2026-09-19｜設計草案 v0.1｜**DESIGN_DRAFT_OFFLINE_CHECKED**

**同じ持寄り資料から「共同観測の行を書き直す」方式と「採用する行を選び、その行全体を保存する」方式を比較する。全4組・通常32要求を推奨する。** 選ぶ判断はモデルに残し、管理側は選んだ行をそのまま複製する。

今回は設計・素材・採点・ローカル点検まで。**新規研究モデル要求0、実認証0、取得器未接続。** 接続準備と実送信は次段階。

## 1. 何を切り分けるか

[SM02の二巡目](shared-merge-02-results-v0.1-2026-09-19.md)は主3/4組、内容感度4/4組だった。G03/Bは相手の新しい観測値と版3を保存できたが、元IDに旧`SM3A`を残し、後の2回答にも引き継いだ。

今回の問いは、**「どの観測を採るか」と「採った観測を書き写すこと」を分ける設計で、出典まで含む保存と、その後の利用が成立しやすくなるか。** 主対象を共同観測の統合に絞る。UPDATEで旧資料も根拠として挙げた別の問題は、この比較では介入しない。

文系向けには、同じ二冊のノートを渡して比べる。

| 条件 | モデルがすること | 保存されるもの |
| --- | --- | --- |
| **REWRITE：書き直す** | A/Bそれぞれの採用情報を選び、人物・届き方・版・出典IDを出力する | モデルが書いた行を保存 |
| **SELECT：行ごと持ち越す** | A/Bそれぞれについて、入力のどの行を採るか指定する | 指定された行を、人物・届き方・版・出典IDごと複製して保存 |

例として「相手の冊子のA行を採る」と指定したら、その行をそのまま保存する。「もっと新しい行が別にある」と管理側が判断して差し替えることはない。旧行や別人の行を選んだ場合も、その選択を残す。

**一行をそのまま複製すれば欄の混在を防げること自体は、仕組み上の性質。** それを実測によるモデル能力向上とは数えない。今回測るのは、正しい新しい行を選び、本人情報を保ち、保存後の判断まで成立させられるかである。

## 2. どの資料から始めるか

SM02の**全4組・両役が実際に受け取ったMERGE直前の入力8件**を固定する。各入力は本人の個別ノート、自分の共同草稿、相手の共同草稿の3資料。UPDATEで生成されたmemoryが元になっており、過去の受領票は含まない。

今回はSM02最終ノートを使う三巡目ではなく、統合前の同じ保存地点から二つの方式へ分岐させる比較。SM02の回答や主3/4は書き換えない。**両条件を新しく実行し、過去の失敗回答をREWRITE対照に流用しない。**

- G03だけを選ばず、G01〜G04のA/Bすべてを使う。UPDATEの主採点に不備があったG03/Bも除外しない。
- 両条件の資料本文・順序・役・場面は同一。初回の資料JSONは既存入力との一致を確認する。
- 本人の担当客情報と観測は実入力から渡す。相手の個別ノート、元の新通知、過去の回答、失敗箇所の説明、正解表は渡さない。
- 各入力で、自分側の新行／相手側の旧行と、相手側の新行／自分側の旧行が混在する。どちらか一冊を丸ごと採ると統合は成立しない。

## 3. 揃える部分と変える部分

**介入するのは、共同ノートのA/B観測行の出力契約と、保存時の実体化。** 個別ノートは両条件ともモデルが同じ形式で記述する。個別ノートをSELECTだけ自動で正しく保存することはない。

| 項目 | 両条件で共通／異なる点 |
| --- | --- |
| 初回資料・役・資料内順序 | 同一 |
| 選ぶ基準 | 同一観測者の正式なrevisionで新版を選ぶ |
| 個別ノートprivate_note | 同じschema、同じ保持要件、モデルが出力 |
| 今回の根拠read_receipt | 同じschema、列挙した各参照による支持を要求、モデルが出力 |
| 共同行shared_note.coverage | REWRITEは行全体、SELECTは場所指定を出力 |
| 次の判断PROBE | 同じ指示・schema。各条件の実保存ノートだけを渡す |
| モデル・生成設定 | Luna medium、新規context、toolsなし、単列を候補とする |

SELECTは共同A/B欄ごとに、例えば `{"record_id":"PARTNER_GROUP","observer":"A"}` と返す。管理側は現在入力のその場所を読み、行の全欄を複製する。値を生成し直さず、並べ替え・最新版探索・正解表との照合による差替えを行わない。

選べる実在行は、本人PRIVATEのcoverage1行、LOCAL_GROUPのA/B2行、PARTNER_GROUPのA/B2行の計5行。本人行はPRIVATEとLOCAL_GROUPの双方に同内容があり、どちらを選んでも正しい場合は認める。**宛先A欄にB行を選ぶことも、実在する指定なら門番では通す。** 保存後に人物の誤りとして採点するためである。

参照名や行が存在しない場合、型違い、余分な欄、JSON重複キーなどは拒否し、推測で別行へ接続しない。SELECTの指定欄へorigin_idを付け足す出力も受理しない。選んだ入力行自体の出典が誤っていても、管理側はそれを修理しない。

保存証拠には、原回答・選択指定・指定先の本文hash・実体化したmemoryを別に残す。受領票は処理/入力/参照先のhashに結び付けて保存し、PROBEには配送しない。次入力には方式名・選択指定も入れず、両条件とも同じ形のPRIVATE/GROUPを渡す。

SELECTの有効出力は実在する行の指定で、自由記述のUNKNOWN行を新しく作る契約ではない。一方、REWRITEのschemaは従来のUNKNOWN表現を保持する。選択不能時の扱い・出力量・出力形式も含む**方式全体の比較**であり、コピーという一要素だけの効果やモデル内部の記憶機構は同定しない。今回の全固定入力には、必要な正しい行が存在する。

## 4. 32要求の割付

| 工程 | 要求数 | 内容 |
| --- | ---: | --- |
| MERGE | 4組×2役×2条件＝16 | 同じ持寄り資料から各方式で統合・保存 |
| PROBE | 4組×2役×2条件＝16 | 自分の方式の実保存ノートで、犬猫・案内とその出典を答える |
| 合計 | **32** | 初回16入力＋生成物依存16入力 |

節約のためPROBEは各一回。SM02での同入力2反復は今回追加せず、反復安定性の比較は主張しない。MERGE全枠の後にPROBEへ進み、段階内はseed2026091905で割り付ける。

同じ組・役の2条件を近接させ、各役4ケースのうちREWRITE先とSELECT先を2件ずつにする。PROBEでは先後を反転する。モデルの乱数を同一に固定した対ではなく、同じ資料に条件を対応させた対である。資料内のLOCAL先／PARTNER先は元入力を保ち、条件間で同じにする。[全32枠と依存]（原資料：`study2/designs/row-carry-01-20260919/allocation.json`）。

両条件とも相手の今回のMERGE結果を見ない。1つのMERGEに依存するのはその役・条件のPROBE1枠だけ。他条件や別役の成功ノートから補わない。

## 5. 主指標・予想・欠測

各条件の **M_END＝両役のMERGEとPROBE、計4枠がすべて成立した組数÷4**。成立条件はSM02から維持し、人物・内容・版・元ID・現在参照・実入力による支持を含む。保存時の個別customer/coverageと共同A/B行、その後の犬猫/案内の各欄を分けて採点する。

**主比較は Δ＝M_END_SELECT−M_END_REWRITE。方向予想はΔ≥.25、すなわちSELECTが1組以上多く成立すること。** 工学的な小標本予想で、検出力から計算した標本数や有意差判定ではない。

| 観測 | 固定する結論 |
| --- | --- |
| 差の下限が.25以上 | MET_IN_FIXED_SAMPLE |
| 差の上限が.25未満 | NOT_MET_IN_FIXED_SAMPLE |
| その他 | INCONCLUSIVE |

各条件の下限は既知成功組/4、上限は（既知成功＋不明組）/4。差は `[SELECT下限−REWRITE上限, SELECT上限−REWRITE下限]`。既知のFalseは不明より優先する。上下限は信頼区間ではない。閾値到達と完全取得は別記録にする。

**両条件4/4で差0なら、今回の改善予想には未達として閉じる。** SELECT優位がないことを一般的な同等性の証明にせず、誤りが出るまでNや試行を追加しない。差が負でもそのまま残す。

事前内容感度では元ID・受領票・入力支持だけを外し、人物・観測値・版・最終判断を残す。主結果の代用にしない。条件ごとの内容不成立、本人情報の損失、旧行・別人行の採用、出典の混在、根拠不備、最終UNKNOWNを併記し、主が良くても内容が悪化したケースは隠さない。安全な非劣性や一般的優越性は主張しない。

SELECTが実在行を複製した事実は構造保証の点検として別集計。入力中のどれか一行と一致しても、古い行や別人の行なら成功ではない。PROBEで再び出典を書き間違える可能性も、両条件共通で残る。

独立した新規8組でも32個体でもなく、既知の同じ4組を条件へ分岐した対応比較。p値・一般成功率・長期共存の証明は今回の対象外。
