# EU01 材料案

[設計書](../docs/experience-update-01-plan-v0.1-2026-09-28.md)のオフライン材料。`materials-proposal.json`は期待値・既知成績を含むため、モデル入力として丸ごと使わない。現段階はDESIGN_ONLYで、全文プロンプト・schema・Colab実行コードは未固定。

- AC01 VERIFY_ACCEPTの本体16出発点を継承。合意15／未合意M05を保持。
- 各出発点で反転／補強の新経験へ分岐。既存経験は実入力の提示順で保存し、新しい一行の二成功人数だけを条件間で交換。
- 32分岐×再提案・相手確認・USE二役＝128回答。初回32、生成依存96。
- 累積成功率を各区画40人へ換算した算術期待値、旧共同割付からの適切な移行、回答ID・依存・seed・実行順を含む。
- `source_bindings`は元ZIP内のファイルhashと抽出箇所。元ZIPのhashは材料表に固定。モデルの実回答ではなく、その内の欄を正解に置き換えた資料は作らない。

点検器 (see the evidence index)は標準ライブラリのみで材料と点検結果 (see the evidence index)を再生成する。ネットワーク・モデルロードなし。1,960点検PASS（元ZIPの1,311ファイル照合を含む）。
