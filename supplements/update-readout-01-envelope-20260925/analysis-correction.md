# 事後分析の照合コード訂正

初回の正規化テスト15件は全通過。意味採点・各原文照合と72件の派生記録保存も完了した後、分析スクリプトの集計比較assertが停止した。

原因は、後続までの成績を含む集計オブジェクトを丸ごと正式集計と比較したこと。このオブジェクトには後続の成否とは別に `private_customer` が含まれる。今回の再評価で37件の本人情報が評価可能になったため、この成分は正式集計と異なってよい。

訂正は比較範囲のみ。各系列の後続完全一致、集合別・反復別の後続成績、固定目安判定は旧結果と比較し、本人情報成分は正規化後の評価を別記する。外装処理・凍結済み採点関数・各原文・派生値は変更していない。初回コードと派生記録はattempt-1/、失敗ログはanalysis-attempt-1.logに保持した。分析全体を同じ原文から再実行する。

二回目は、率の差と件数差を浮動小数点で厳密等号比較したassertで停止した。修復の0.05と0.050000000000000044が表現誤差で不一致になるため、件数の整数照合を保持し、率の照合のみ絶対誤差1e-12以内へ変更した。採点値・分母・判定規則は変更していない。二回目のコード・派生記録・失敗ログもattempt-2/とanalysis-attempt-2.logに保持する。
